# 앱 안의 AI 프롬프트 원문

Tachyon 앱이 Claude API에 보내는 프롬프트를 고치지 않은 그대로 둔다. 부르는 곳은 [`worker/llm.js`](../llm.js) 한 곳이고, 답은 `answer` 도구 하나를 꼭 쓰게 해서(tool_choice) 정해진 JSON 모양으로만 받는다.

| 파일 | 쓰는 곳 | 모델 | 하는 일 |
|---|---|---|---|
| [memo_popup.js](memo_popup.js) | [3_memo_popup.js](../3_memo_popup.js) | 빠른 모델(Haiku 5.5) | 메모 한 줄 → 일정인지 · 이름 · 날짜 · 시각 · 장소 (즉시 팝업) |
| [night.js](night.js) | [4_night.js](../4_night.js) | 똑똑한 모델(Sonnet 5.5) | 01:30 밤 정리: 그날 메모 → 할 일 후보, 할 일마다 걸리는 시간 · 지금 가능 / 수업·자료 뒤 |
| [timetable_photo.js](timetable_photo.js) | [5_timetable_photo.js](../5_timetable_photo.js) | 똑똑한 모델(Sonnet 5.5, 사진 읽기) | 시간표 사진 → 요일 · 시각 · 과목 · 강의실 목록 (앱에 OCR 없음) |

## 모든 프롬프트가 지키는 규칙 (11-09 '아이디어 회의 1')

AI가 일을 부풀리지 않게 한다.
1. **쓴 말 그대로** 제목을 단다. 바꿔 쓰거나 꾸미거나 덧붙이지 않는다.
2. 요청이 없으면 일을 **쪼개지 않는다**. 메모 하나에서 일정·할 일은 하나까지.
3. **모르는 칸은 '?'**. 지어내지 않는다.

## 코드가 먼저 하는 일

- 날짜·시각(오늘·내일·다음주 화요일·3시 반 …)은 정규식으로 먼저 계산한다([3_memo_popup.js](../3_memo_popup.js)의 `findWhen`). AI는 일정인지, 이름, 장소와 오전·오후를 짐작해야 할 때의 시각만 보탠다. AI 답이 늦거나 실패해도 팝업은 규칙만으로 뜬다.
- 날짜·시각 말이 없는 메모는 AI를 부르지 않는다(비용·지연 0). 그런 메모는 밤 정리가 읽는다.
- 밤 정리의 마감 날짜도 정규식이 '메모를 쓴 시각' 기준으로 먼저 센다. 할 일 순서(여유 적은 순)·몰린 주 경고·브리핑 카드는 AI 없이 코드가 계산한다([4_night.js](../4_night.js)의 `rankTasks`·`crowdedWarning`).
- 시간표 사진은 사용자가 확인 팝업에서 고친 뒤에만 일정이 되고, 사진은 저장·취소하면 바로 지운다.
- log 표에는 사용량(모델·ms·토큰 수)만 남기고 메모 글·답 내용은 남기지 않는다.
