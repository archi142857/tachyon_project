# Tachyon — 서울대생 세컨브레인

**eTL 과제·캘린더·시간표·메모를 한곳에 모아, 할 일 3개·주간 달력·메모 화면과 아침 브리핑으로 정리해 주는 서울대생용 웹앱·앱입니다.** 메모에 일정처럼 보이는 글을 쓰면 바로 '이대로 저장할까?'를 묻고, 밤에는 그날 메모를 정리해 아침에 먼저 할 것과 미룰 것을 알려 줍니다.

**지금 상태 (2026-11-09): 개발 0단계.** 서버 뼈대만 배포돼 있고 아직 쓸 수 있는 기능은 없습니다. 11/13 팀 실사용 → 11/25 기능 동결 → 11/29 제출 예정입니다. 날마다 바뀌는 진행은 [계획](docs/tachyon/계획.md)의 체크박스와 [소통판](docs/tachyon/소통.md)에서 볼 수 있습니다.

## 무엇을 해결하나요?

AI는 이미 일을 잘하지만, 대부분은 묻고, 답을 읽고, 그 결과를 캘린더·메모 앱에 손으로 옮깁니다. 다음 주에는 같은 설명을 처음부터 다시 합니다. 과제 마감은 eTL에, 수업은 시간표에, 약속은 캘린더에, 떠오른 일은 메모에 흩어져 있습니다.

Tachyon은 이것들을 한 달력과 할 일 목록으로 모으고, 학생이 이미 익숙한 화면(달력·할 일·메모·알림) 안에서 AI가 정리를 대신하게 하려고 합니다. 명령어를 배울 필요가 없게 하는 것이 목표입니다.

## 어떻게 돌아가나요? (계획)

```
eTL 과제·시험 ─┐
시간표 사진 ───┤
캘린더(ICS) ───┼──▶ 달력 + 할 일 ──▶ 대시보드: 할 일 3개 · 주간 달력 · 메모
메모(나와의 채팅)┘                ──▶ 아침 브리핑(먼저 할 것 · 미룰 것)
```

| 화면·기능 | 하는 일 |
|---|---|
| 할 일 3개 | 마감까지 여유가 적은 순서로 세 개만 보여 줍니다. 몰린 주는 미리 알려 줍니다. |
| 주간 달력 | 수업·과제·약속을 한 주에 겹쳐 보여 줍니다. |
| 메모(나와의 채팅) | 생각나는 대로 적습니다. 일정처럼 보이면 시간·이름·장소를 채운 확인 창이 바로 뜹니다. |
| 아침 브리핑 | 밤 01:30에 그날 메모를 정리해 아침 카드 한 장으로 줍니다. 알림은 하루 이 한 번뿐입니다. |
| 연결 | eTL·구글·애플 캘린더는 ICS 주소로 읽습니다. 시간표는 사진으로 올리면 AI가 읽습니다. |

AI가 일을 부풀리지 않도록, 할 일 제목은 사용자가 쓴 말 그대로 두고, 요청이 없으면 일을 쪼개지 않으며, 모르는 칸은 '?'로 남깁니다.

## 기술

- 서버: Cloudflare Workers · D1(DB) · R2(시간표 사진) · Cron. DB 표는 [schema.sql](schema.sql)(초안).
- 화면: 웹(PWA) 하나의 코드로 먼저 만들고, 같은 코드를 Capacitor로 감싸 안드로이드·아이폰 앱을 만듭니다.
- 앱 안의 AI: Claude API(즉시 확인 창 = Haiku, 밤 정리·브리핑·시간표 사진 = Sonnet).

## AI를 어떻게 활용했나요?

- 개발은 팀원마다 자기 노트북의 AI 에이전트(Claude Code, Claude)로 했습니다. 사람이 AI에게 준 요청은 [prompts/](prompts/README.md)에 원문 그대로, AI끼리 주고받은 요청·보고는 [소통판](docs/tachyon/소통.md)에 남깁니다. 도구 칸에는 실제로 쓴 도구를 적습니다.
- 공모전 규정은 [공모전 규정 확인](docs/tachyon/공모전.md)에 정리했습니다. ChatGPT Edu에서 Tachyon을 부르는 MCP 연결을 3단계에 넣었고, ChatGPT Edu를 개발에 쓴 경우에는 그때 기록합니다.

## 직접 돌려 보기 (개발자용)

```sh
npm install
npm run db:local
npm run dev
# http://localhost:8787/api/health → {"ok":true,"tables":6}
```

비밀값(API 키 등)은 `npx wrangler secret put 이름`으로만 넣고 저장소에 적지 않습니다. 실제 일정·이름·학번·캘린더 주소도 저장소·예시·캡처에 넣지 않습니다.
