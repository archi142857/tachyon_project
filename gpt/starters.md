# 대화 시작 문구 4개 — 미적용 초안

1. 가상 이수내역을 붙여 넣을게요. 취득 완료·수강 중·미확인을 구분해 먼저 확인해 주세요.
2. 가상 동물생명 주전공·생명 복수전공 사례에서 목록 대조와 확인이 필요한 요건을 나눠 주세요.
3. 가상 사례로 다음 학기 시간표를 비교하고 싶어요. 원하는 학점과 피할 시간을 한 번에 물어봐 주세요.
4. 계산된 시간표에서 걷는 시간·부족한 이동 여유·미정 강의실·예상 개설을 쉽게 설명해 주세요.

설정 시 위 문장만 각각 한 칸에 넣는 안입니다. 입력·계산 없이 완성된 추천 결과가 있는 것으로 소개하지 않습니다. 가상 입력은 [demo/가상_입력.md](../demo/가상_입력.md)에서 준비하며 생성 묶음에 자동 포함되는 파일은 아닙니다.
