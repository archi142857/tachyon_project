# GPT 설정

2026-11-07. **작업 4 설정 초안을 작성했습니다. 실제 GPT에 적용하거나 파일을 업로드·공유·이전하지 않았습니다.** 학교 Edu 계정의 생성·편집·실행 권한과 적용 종료일은 미확인입니다. 계산 묶음의 로컬 검증과 실제 GPT 통합을 구분합니다.

`knowledge/`는 Planner의 `scripts/build_gpt.py`가 만드는 제외 대상 폴더입니다. 직접 편집하지 않으며 지침 작성만으로 파일 생성·무결성·실제 GPT 실행이 성공했다고 표시하지 않습니다. 설정 초안도 프롬프트 원문이므로 [작업 4 기록](../prompts/Frontend-09-GPT지침-묶음검증.md)에서 연결합니다.

학생이 만든 비공식 도구예요. 졸업 사정은 학과와 마이스누에서 최종 확인하세요. 다른 사람의 성적표는 올리지 마세요.
