# Project / Concept · 프로젝트 안의 여러 채팅 확인

- 날짜: 2026-11-07
- 도구: Codex
- 목적: 프로젝트 운영과 실제 변경을 확인하고 다음 작업을 안내한다.

## 프롬프트 원문

````text
엥 잠만 GPT는 프로젝트 밑에 세션 여러 개 못 넣음?
````

## 결과 요약

OpenAI 공식 프로젝트 안내를 확인해 한 프로젝트에 여러 채팅을 둘 수 있음을 설명했다. 앞서 만든 시작 프롬프트는 로컬 저장소를 읽는 Codex 기준임을 명확히 했다. 일반 ChatGPT 웹 프로젝트에서는 파일 업로드·연결이 필요하다고 설명했다. 근거: https://learn.chatgpt.com/docs/projects . 세션 생성·프로젝트 변경은 수행하지 않았다.
