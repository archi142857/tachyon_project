## 결과 요약

- **시안**: 손그림 2장대로 PC·폰 대시보드 시안 3개를 캔버스에 그렸다(A 손그림 그대로 · B 달력 크게 · C 메모 크게, 팝업 모양도 셋 다 다름). 사용자가 **A**를 골랐다. 이름은 Tachyon.
- **색**: 첫 색 3안(청록·밤하늘·주황) 뒤에 사용자가 Dropbox 브랜드 페이지를 참고로 줬다. 페이지를 열어 핵심 색(코코넛 #F7F5F2 · 그래파이트 #1E1919 · 파랑 #0061FE)과 짝 색, 각진 모양을 보고 A 폰에 3안(코코넛·그래파이트·짝 색)을 다시 칠했다. 로고·전용 글꼴은 쓰지 않는다. 고르기 전까지 코드는 '코코넛'으로 칠했다(`web/src/styles.css`의 `:root` 한 곳).
- **로그인 화면 틀**: 레포·공유 드라이브에서 회의 때 만들던 화면 틀을 찾지 못해 Vite + React로 시작했다.
- **web/**: PWA(manifest·아이콘·서비스 워커, 아이폰 안내 포함), 로그인 화면, 첫 설정(학과·학년 + eTL·구글·애플 주소 칸, 찾는 법 한 줄씩과 '자세히', 칸마다 모양 확인, 건너뛰기), 대시보드 A(할 일 3개 · 메모 · 주간 달력 · 아래 긴 메모 칸 · 메모 즉시 팝업 저장/고치기/취소 · 눌러서 고치기 · 햄버거 메뉴 · 의견 버튼 · 화면 오류 자동 보고). 서버 없이 '예시로 둘러보기'(지어낸 '예시' 자료).
- **서버·AI와 맞춤**: 작업하는 동안 올라온 `/api/login*`·`/api/feeds`·`/api/tasks`·`/api/events`(서버), `/api/memo*`(AI)의 실제 모양에 맞췄다(할 일 3개 = `/api/tasks` 여유 순 + 경고, 캘린더에서 온 항목은 고치기 잠금). 아직 없는 `/api/feedback`(6_feedback)은 바라는 모양을 [web/API.md](../web/API.md)에 적고 쪽지로 부탁했다.
- **서버 쪽지(11-09 18:00) 반영**: 캘린더 주소 저장 결과를 `results`로 읽는다 — 저장 안 된 칸(`saved: false`)은 붙인 주소를 남기고 서버 문장을 칸 아래에, 저장된 칸은 '과제 N개를 찾았어요'. 첫 설정은 결과를 보인 뒤 [다음]. 메뉴에서 다시 열면 지금 상태 한 줄(멈춘 주소는 '다시 붙여 주세요')과 [지금 다시 받기]. 메모·시간표에서 온 일정·할 일은 [지우기](두 번 눌러야), 메뉴 '폰 달력에서 보기'(내 구독 주소·복사·webcal). 여유(`slack_days`, 소수)는 내림해서 '여유 N일'·'빠듯'. 고치기 실패는 창 안에, 창이 열려 있을 때 알림 막대는 창 안 위쪽에.
- **그 뒤(멈추지 말라는 말대로)**: 의견 보내기를 서버 6_feedback 모양(kind bug·pain·idea)에, 할 일 '수업·자료 뒤' 바꾸기, 쓰는 도중 로그인이 끝나면 로그인 화면으로·연결 끊김 안내, 아이폰 홈 화면 앱 로그인 안내. 배포 주소에서 Chrome '앱 설치 가능' 판정 통과. 2단계 '아침 브리핑 카드' 시안 3개(맨 위 카드 · 아침 한 장 · 띠 + 아래 창)를 캔버스에 올리고, 색·브리핑 고르기와 실제 폰 확인은 새 규칙대로 컨셉에 '사용자-' 쪽지로 보냈다.
- **팀 공유 파일**: `wrangler.toml`에 `[build]`(dev·deploy 때 web 빌드)와 `[assets] directory = "web/dist"`, 한 페이지 앱 처리, `/api/*`는 Worker 먼저를 넣었다. `web/index.html`은 빈 화면 대신 앱 입구가 됐다. 소통판에 알림.
- **확인**: Vitest 29개, worker 시험 89개 통과. 로컬 `wrangler dev`(진짜 worker + 로컬 D1의 지어낸 예시 자료)로 첫 설정 → 대시보드 → 체크·되돌리기 → 고치기·지우기 → 잠금 → 할 일 전체 → 폰 달력 → 메모 팝업(키 없어서 규칙) 저장 → 다시 연 설정·다시 받기 → 로그아웃까지 API 38번(200 36번, 일부러 낸 400 한 번, 아직 없는 의견 API 501 한 번)이 기대대로 왔다. 처음 확인: 헤드리스 Chrome으로 폰(390×844)·PC(1280×800)에서 예시 흐름(첫 설정 오류 → 건너뛰기 → 대시보드 → 메모 '내일 3시 301동 스터디' → 팝업 → 저장 → 달력에 들어감 → 메뉴·할 일 전체·의견)을 돌려 콘솔 오류 없음, 서비스 워커 등록 확인. `wrangler deploy --dry-run` 성공, `wrangler dev`에서 화면·한 페이지 앱·`/api/health`·`/api/login/me`(401) 길 확인, 로그인 실패(`?login_error=config`) 화면 확인.
- **아직**: 실제 폰에서 '홈 화면에 추가'(배포 뒤), 구글 로그인·진짜 일정으로 확인(비밀값 넣은 뒤), 6_feedback(서버가 만드는 중, 지금 501), 색 고르기, 아침 브리핑 카드·시간표 사진 화면(2단계).
