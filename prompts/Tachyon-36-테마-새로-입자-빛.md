# Tachyon-36 · 테마 새로 짜기(입자 빛 되살림 · 태양계 · 오선지 · 뉴모피즘), 원자 모형 빼기

- 날짜: 2026-11-19
- 도구: Claude Code (VS Code 확장, Claude Opus 5.5) — 화면 확인은 헤드리스 Chrome(CDP로 직접 부르는 node 스크립트, 예시 모드, 넓은 화면 1440×900 · 폰 390×844)과 ffmpeg(여러 장 이어 붙이기), 대비 계산은 python, 시험은 vitest, 빌드는 vite build, 글꼴 빼기는 npm uninstall
- 기록 유형: 사용자 직접 지시
- 목적: 테마들이 바우하우스에 색만 바꿔 입힌 것처럼 보여 내용과 디자인이 따로 노는 느낌을 없앤다. 입자 테마의 빛(glow)을 되살린다.

## 프롬프트 원문

11-19 01:08

````text
디자인 수정을 할거야. 전체적으로 내용과 디자인이 동떨어져있다는 느낌이 들어. 특히 입자 테마는 내가 원래 디자인했던 것과 차이가 조금 많이 나는 것 같아. 입자 테마는 glow한 느낌이 핵심인데, 너무 flat하게 되어서 매력이 사라진 것 같은 느낌이야. 지금 디자인들이 다 바우하우스를 시작으로 간 것 같은 느낌인데, 그럴 필요 없어. 좀 더 새롭게 해주고, 바우하우스를 시작으로 다른 옷을 입힌다는 느낌이 아니라, 그냥 시스템과 기능, 위치만 통일하고 나머지는 다 바꾸는 쪽이라고 생각해. 시스템은 같지만, 레이아웃이 같을 필요는 없을 것 같아. 바우하우스만 빼고 다 수정해줘. 그리고 원자모형 테마는 없애줘.
````

## 결과 요약

- **같게 둔 것**: 부품과 기능, 자리(왼쪽 메뉴 · 머리 줄 · 오늘 칸 넷 · 아래 전체 폭 적기 칸 · 로고). 11-15 '자리 통일'과 11-15 '적기 칸 아래 전체 폭'은 그대로.
- **테마마다 따로 짠 것**: 칸 나누는 법, 오늘 칸 비율(넓은 화면 three · ring 배치), 단추 · 글자 · 일정 칸 · 할 일 고르기 칸 · 메모 · 적기 칸 · 지금 줄 모양.
  - **입자**(`nine.css`): 시연 9판 · 옛판 `입자-고리.html`의 빛을 되살림 — 화면 뒤 보라 · 청록 · 분홍 빛 번짐, 유리 칸(가장자리 빛 · 번짐), 일정 · 할 일 · 고리 입자가 제 색으로 빛남, 빛나는 적기 칸 · 시트 · 말풍선. 고리를 가운데 크게. 밤 · 낮 모두.
  - **태양계**(`looks/태양계.css`): 별 지도 · 천문대 계기판. 칸은 금빛 모서리 눈금만 있는 얇은 판, 고리는 테 없이 우주에 떠 가운데를 크게, 칸 이름은 넓게 벌린 금빛 표지, 일정은 행성 빛 캡슐, 지금 줄은 혜성, 할 일 고르기는 고리 두른 행성 → 해.
  - **오선지**(`looks/오선지.css`, 값 새로): 상아색 악보 종이 한 장을 먹 괘선으로 나누고 겹줄로 두름(칸마다 상자 없음). 칸 이름 앞 악장 번호(I · II · III), 메뉴는 프로그램 차례(로마 숫자 + 빨간 음표 머리), 머리 줄은 오선 위 + 높은음자리표, 할 일 고르기는 음표 머리, 메모는 여백 주석. 11-13의 검은 띠 바탕은 앱에서 뺌(시안에만).
  - **뉴모피즘**(`looks/뉴모피즘.css`, 값 새로): 연회색 · 파랑 → 따뜻한 점토 · 테라코타. 왼쪽 메뉴는 떠오른 도크, 고리는 테 없는 원반, 할 일은 하나하나 볼록한 알약(고른 것 = 눌림), 오늘 일정은 오목한 홈 위 볼록한 일정, 적기 칸은 오목한 홈 + 볼록한 보내기 손잡이. 고리 그림 · 로딩 화면 색도 같이.
- **원자 모형 뺌**: `themes.js`(목록 · 로딩), `themes.css`, 고리 `원자.jsx` · `index.js` · `Backdrop.jsx` · `art.css` · `loader.css`, 글꼴 `@fontsource/orbit` · `@fontsource-variable/orbitron`, 시안(`web/design`), 문서. 원자 모형을 골라 둔 기기는 바우하우스로.
- **확인**: 다섯 테마 × 넓은 화면(오늘 · 달력 · 할 일 · 메모) · 폰 오늘 화면을 찍어 봄, 바우하우스는 그대로. 테마 값 대비 시험(themes.test.js) 포함 web 시험 194개 통과, vite build 통과.
