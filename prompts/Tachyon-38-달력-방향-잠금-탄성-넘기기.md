- 도구: Claude Code (Claude 데스크톱 앱 Code 탭, Claude Opus 5.5) — 앱 안 브라우저(예시 모드, 폰 폭 375)에 손가락(pointer, touch) 이벤트를 직접 보내 확인, node로 용수철 계산, vitest · vite build. 실제 폰 손가락(브라우저의 방향 잠금)은 이 노트북에서 못 돌려 사람 확인
- 기록 유형: 사용자 직접 지시

## 원인

- 달력 칸 하나가 위아래 · 옆을 다 브라우저 굴리기로 했다(`overflow: auto`). 손가락이 비스듬하면 두 방향이 같이 움직였고, 옆은 날 칸마다 붙는(`scroll-snap-type: x mandatory`) 탓에 내리다 옆으로 툭 붙는 일이 났다.
- 옆으로 튕기면 하루 단위로 미끄러져 몇 칸 갈지 들쭉날쭉했다(한 화면씩이 아님).

## 한 일

- 칸과 그 안 모두 `touch-action: pan-y`(`feedback1114.css`, 고른 일정 · 길이 손잡이는 그대로 none): 손가락은 위아래만 브라우저가 굴리고, 처음 움직임이 옆이면 브라우저가 손을 떼어 JS로 넘긴다 = 방향 잠금.
- 새 `web/src/components/useSwipe.js`: 옆 손가락을 1:1로 따라가고, 놓으면 한 화면(n일) 앞뒤 또는 제자리(빠르게 튕김 0.3px/ms 넘음 또는 한 화면의 30 % 넘게 끎)를 골라 용수철로 붙는다(tension 200 · friction 18, 튕기면 약 12px 지나쳤다 0.5초에 멈춤). 미끄러지는 중에 다시 잡으면 그 자리에서 이어서, 끌고 난 뒤 click은 먹어서 일정 넣기 창이 뜨지 않게, 두 손가락(확대 · 축소)이 오면 제자리로. 동작 줄이기 설정이면 바로 붙음.
- `WeekCalendar.jsx`: 넘기는 동안은 '멈춤'(start 옮기기)을 기다리고, 붙으면 scrollend로 start를 옮긴다. 마우스 · 트랙패드는 예전 그대로.
