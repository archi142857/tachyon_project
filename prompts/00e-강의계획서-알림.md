# 00e. 강의계획서 모아보기와 등록 알림

- 날짜: 2026-11-06
- 도구: Codex
- 목적: 과목마다 다른 강의계획서 업로드 시점을 반복 확인하는 불편을 서비스 요구사항에 반영한다.

## 프롬프트 원문

````text
강의 계획서 모아서 보는 게 필요..
강의 계획서 업로드 시점이 달라서 일일이 확인하는 과정이 필요
강의 계획서가 업로드 되었다는 알림이 필요.
````

## 결과 요약

관심 과목의 계획서 등록 상태와 원문 접근 경로를 모아 보고, 새 등록을 확인하면 알리는 흐름을 정리했다. 미등록·미확인·조회 실패를 구분하고 최초 확인과 실제 상태 변화, 중복 알림 방지 기준을 적었다.

현재 강좌 자료에는 계획서 등록 여부가 없어 실제 조회·알림은 미구현으로 표시했다. 공식 조회 경로, 확인 주기, 알림 수단을 확인할 사항으로 남겼다. 개인 알림을 설정하거나 메시지를 발송하지 않았다.
