# Tachyon-33 · 달력 좌우 굴리기: 멈출 때 끊기던 것

- 날짜: 2026-11-16
- 도구: Claude Code (Claude 데스크톱 앱 Code 탭, Claude Opus 5.5) — 앱 안 브라우저(예시 모드, 폰 폭 375)에서 scroll · scrollend · 터치 이벤트를 직접 보내 확인, vitest · vite build. 실제 폰의 손가락 튕기기(fling)는 이 노트북에서 못 돌려 아직
- 기록 유형: 사용자 직접 지시
- 목적: 손으로 튕긴 달력이 미끄러지다 날 칸에 멈출 때 중간에 뚝 끊기던 것을 없앤다.

## 원인

- `WeekCalendar.jsx`가 손가락을 뗀 160ms 뒤에 '멈췄다'고 보고 start를 옮겼다. 튕긴 화면은 그때도 미끄러지는 중이라, start를 옮기며 굴린 자리를 가운데로 되돌리는 순간(`scrollLeft` 다시 쓰기) 미끄럼이 끊기고 그 자리에서 날 칸으로 붙었다.
- 멈출 때마다 그려 둔 날 칸 전체(3일 보기 17칸 · 주 35칸)를 하루씩 밀어 다시 그리고 굴린 자리를 되돌렸다 — 폰에서는 그 한 장면이 튀어 보일 수 있다.

## 한 일

- 멈춤은 마지막 scroll에서 160ms 뒤(scrollend가 오면 그때), 손가락이 닿아 있지 않을 때만. 미끄러지는 동안은 scroll이 계속 오니 옮기지 않는다.
- 그려 둔 날들은 `anchor`를 가운데로 둔 채 그대로 두고, 멈추면 start(제목 · '오늘' · 메모 날짜)만 옮긴다. 앞뒤로 한 화면(n일)보다 적게 남거나 '오늘'처럼 밖으로 뛸 때만 start를 가운데로 다시 그린다(화면은 그대로).
- 대시보드는 보이는 날 앞뒤로 2·calPad일을 불러 둔다(그려 둔 칸이 start에서 calPad일까지 떨어져 있을 수 있어서).
- 확인(예시 모드 · 375 폭): 멈출 때 제목만 바뀌고 칸은 그대로, 가장자리에서만 다시 그림(보이는 날 그대로), '오늘' · 하루/3일/주 바꾸기, 손가락이 닿은 동안과 손을 떼고 미끄러지는 동안은 안 옮기고 마지막 scroll 160ms 뒤에 옮김. vitest 198 · 빌드 통과.
- 남은 것: 실제 폰에서 튕겨 보기.
