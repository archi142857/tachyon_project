# 00f. 로그인 이후의 자동화

- 날짜: 2026-11-06
- 도구: Codex
- 목적: 학생의 반복 입력을 줄이고 로그인 후 이수내역 불러오기부터 시간표·강의계획서 알림까지 자동으로 이어지는 목표를 정리한다.

## 프롬프트 원문

````text
그리고 최대한 이 작업들이 다 자동으로 일어났으면 좋겠음. 내부 브라우저에서 로그인 하면 자동으로 수강했던 강의들 불러온다던지.
````

## 결과 요약

학교 로그인 → 이수내역·전공 정보 불러오기 → 요약 한 번 확인 → 졸업요건·시간표 계산 → 선택한 과목의 계획서 모아보기·알림으로 이어지는 목표를 정리했다. 이미 읽은 정보를 반복해서 묻지 않고 부족한 항목만 한 번에 받도록 했다.

로그인 성공과 전체 이수내역 조회 성공을 구분하고, 부분 조회·수강 중 과목·로그인 만료·계정 변경·중복 알림 기준을 적었다. 내부 브라우저 인증과 공식 자료 연결은 확인 필요다. 기존 정보화본부 회신 조건과 GPT Actions 별도 결정 지침을 유지했다. 실제 학교 로그인·조회·알림은 구현하거나 실행하지 않았다.
