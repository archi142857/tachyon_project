# Tachyon · 컨셉 08 · 앱 이름 Tachyon의 뜻

- 날짜: 2026-11-09
- 도구: Claude (claude.ai 프로젝트 세션, Claude Opus 5.5)
- 기록 유형: 사용자 직접 지시
- 목적: 사람이 알려 준 앱 이름의 뜻을 심사위원이 먼저 보는 README와 신청서 초안에 반영한다.

## 프롬프트 원문

````text
참고로 tachyon이라는 단어는 빛보다 빠르다는 의미를 다른 사람들보다 시간을 압축적으로, 남들보다 앞설 수 있는? 이런 느낌의 단어로 지은 이름임
````

## 결과 요약

- README 맨 위 소개 바로 아래에 이름 뜻 한 줄을 더했다: '이름은 빛보다 빠르다고 가정한 입자 타키온(tachyon)에서 따왔습니다. 남들보다 시간을 압축해 쓰고, 한발 앞서 갈 수 있게 하자는 뜻입니다.'
- 신청서 초안 2절에 같은 문장을 '첨부·발표 첫 장에 쓸 한 줄'로 더했다(한 줄 요약 100자 칸은 그대로).
- 우리 쪽 세션이 읽는 프로젝트 배경 문서에도 이름 뜻을 적었다.
