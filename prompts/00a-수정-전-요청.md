# tt-wizard-gpt

## 이 레포가 하는 일
서울대 학생이 이수 과목을 올리면, 졸업요건 중 남은 것을 근거와 함께 알려 주고 다음 학기 시간표 3안을 강의실 사이 걷는 시간까지 따져 추천하는 ChatGPT Edu GPT를 만든다. 이 레포에는 GPT가 쓸 자료, GPT가 코드 인터프리터에서 돌릴 계산 코드, GPT 설정 문서를 둔다.
- ChatGPT Edu 활용 상시 공모전(서울대 정보화본부, 11월 접수, 마감 2026-11-30 23:59)에 낸다. 만든 GPT는 서울대 구성원에게 공유한다.
- 바탕은 같은 개발자가 만든 TT Wizard(코드 https://github.com/Archi142857/tt-wizard, 웹 https://archi142857.github.io/tt-wizard/)다. TT Wizard 레포는 읽기만 하고 고치지 않는다.

## 학생이 겪는 흐름
1. 성적표 PDF를 올리거나 마이스누 성적 화면의 표를 붙여 넣는다. 학번·이름·생년월일은 지우고 과목명·학점·이수 구분만 있으면 된다고 안내한다.
2. GPT가 읽은 과목 표를 보여 주고 한 번 확인받는다.
3. 남은 졸업요건을 표로 보여 준다. 항목마다 출처(문서·조항·링크)를 달고, 애매한 것은 '확인 필요'로 둔다.
4. (선택) 목표 학점, 피하고 싶은 요일·시간, 주로 오는 곳을 한 번에 묻는다. 답이 없으면 기본값으로 간다.
5. 다음 학기 시간표 3안을 보여 준다: 남은 요건을 채우는 과목, 시간 겹침 없음, 연강 사이 걷는 시간과 여유, 빠듯한 구간, 한 주 걷는 시간 합계, TT Wizard에서 바로 열어 동선 지도를 보는 링크.
6. 확인이 필요한 것 목록과 자료 출처 문장으로 끝낸다.
학생이 꼭 해야 하는 일은 1번 하나다. 강좌·걷는 시간·졸업요건은 GPT가 이 레포의 자료로 처리한다.

## 구조
- scripts/: 자료 동기화(sync_ttwizard.py), GPT 묶음 만들기(build_gpt.py)
- data/: GPT용 자료. offerings/{학기}.json, walk.csv, buildings.csv, likelihood.csv는 스크립트로만 만든다. requirements/는 졸업요건 자료.
- planner/: 계산 코드. 파이썬 표준 라이브러리만 쓴다(ChatGPT 코드 인터프리터에서 인터넷 없이 돌아야 함).
- gpt/: GPT 지침·설명·대화 시작 문구·설정 체크리스트, knowledge/(GPT에 올릴 파일, 스크립트로 만듦)
- tests/: pytest. 예시 학생은 모두 지어낸 자료.
- docs/: 작업_목록.md(할 일), 작업_기록.md(한 일), 설계·자료 설명

## TT Wizard 자료 형식
- data/history/{학기}.json (2021-1 … 2026-2, S·W는 계절학기): {"fields", "courses", "meta"}
  - course = [교과목번호, 과목명, 개설 학과, 학점, 이수구분(전필·전선·교양·교직·일선·공통·대학원), 과정(학사·석사·박사·석박사통합), sections]
  - section = [강좌번호, 교수, 상태(빈 글 또는 '폐강대상'), meetings]
  - meeting = [요일(0=월 … 5=토), 시작, 끝(0시부터 분, 840=14:00), 동 번호, 강의실]. 모르는 칸은 빈 글
- data/travel_slope.csv: from,to,minutes,source. 지점 135곳 사이 걷는 시간(분). 경사를 반영해 방향마다 다르다.
- data/buildings.csv(building,name,lat,lon), campus_buildings.csv, dorm_buildings.csv: 지점 이름과 좌표
- ttwizard/(MIT)의 models.py·travel.py·evaluate.py·search.py: 분반 조합 탐색. 비용 = 한 주 걷는 시간 + 2 × 지각 분(연강 사이 여유가 걷는 시간보다 짧은 만큼). 시간 겹침만 '불가'이고, 강의실이 정해지지 않은 수업은 이동·지각을 만들지 않는다. 이 규칙을 그대로 쓴다. 출발·귀가 지점 기본값은 cli.py의 --home 기본값을 따른다.
- 시간표 링크: https://archi142857.github.io/tt-wizard/#t=<글>. 글 = 'j' + base64url(JSON, '=' 없이) 또는 'z' + base64url(deflate-raw(JSON)). JSON = [1, 학기, 제목, [[교과목번호, 강좌번호, null, 과목명], …]]. 받는 쪽이 그 학기 편람으로 채우므로, TT Wizard 웹의 data/semesters.json 목록에 있는 학기일 때만 만든다(web/js/app.js의 '시간표 링크' 참고).

## 꼭 지킬 것
1. 교수 이름은 어떤 파일·출력·GPT 지식에도 넣지 않는다. 동기화할 때 교수 칸을 버린다.
2. 높이 자료(고도, 등고선, 경사 표, 3D 지형, buildings_elevation.*)는 가져오지 않는다. 걷는 시간(분)만 쓴다.
3. 자료 조건: 걷는 시간 표는 ODbL(© OpenStreetMap 기여자, 캠퍼스 마법 지도), 경사를 반영한 몫은 국토지리정보원 수치지형도(공공누리 제1유형), 강좌는 서울대 수강편람에서 왔다. data/README.md, GPT 설명, GPT 답의 끝에 이 문장을 둔다: 'TT Wizard 자료: 캠퍼스 마법 지도·© OpenStreetMap 기여자, 국토지리정보원, 서울대 수강편람'. 코드는 MIT, data/는 ODbL로 계속 공개한다.
4. 실제 성적표·이수 내역(개발자 본인 것도), 학번, 이름, 마이스누 화면을 레포·테스트·예시·캡처에 넣지 않는다. 예시는 지어낸 학생 자료로 만들고 '예시'라고 적는다. GPT는 성적·학번·이름을 계산에 쓰거나 답에 옮기지 않는다.
5. GPT 지침과 지식 파일은 누구나 뽑아 볼 수 있다고 보고, 공개해도 되는 것만 넣는다. API 키·토큰·관리 주소는 어디에도 넣지 않는다.
6. GPT 설명에는 이 문구를 넣는다: '학생이 만든 비공식 도구예요. 졸업 사정은 학과와 마이스누에서 최종 확인하세요. 다른 사람의 성적표는 올리지 마세요.'
7. 졸업요건은 학교·단과대학·학과 공개 문서의 사실만 옮기고, 항목마다 출처(문서·URL·조항)를 단다. 출처가 없거나 해석이 갈리면 needs_check를 true로 두고, GPT가 '확인 필요'로 보여 준다. 추측해서 채우지 않는다.
8. 마이스누 화면을 자동으로 읽는 기능(크롬 확장 등)은 정보화본부 답이 오기 전까지 만들지 않는다.
9. GPT Actions는 사용자가 정할 때까지 쓰지 않는다. 쓰게 되면 깃허브 페이지의 고정 JSON을 GET으로만 읽고, 대화에서 채워지는 자유 글 매개변수는 두지 않는다.
10. 다음 학기 편람이 아직 없으면 지난 같은 학기(2027-1이면 2026-1)의 분반으로 '예상'을 만들고, 결과에 그렇게 했다고 적는다. 개설 가능성은 최근 5년 같은 학기 가운데 열린 해의 수로 본다.
