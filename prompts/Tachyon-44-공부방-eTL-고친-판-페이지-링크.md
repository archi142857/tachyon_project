## 정한 것

- 고친 판 알아보기: eTL은 같은 이름으로 덮어 올리면 번호가 바뀐다 → 방을 열 때 내려간 자료와 '판 표시를 뗀 이름'이 같은 새 자료가 하나씩이면 고친 판. 판 표시 = 끝의 `(1)` · `(수정)` · `[최종본]` · ` v2` · `_rev` · ` final` · `-수정본`. 괄호 없는 숫자만 다른 이름(3강 · 4강, 함수 · 함수2)은 다른 자료다.
- 같은 번호의 eTL 수정 시각(파일 `modified_at`, 페이지 `updated_at`)이 바뀌어도 고친 판(읽었거나 지도가 있을 때만).
- 고친 판은: 범위 '안'만 잇고(예전 판이 범위 밖이었으면 다시 묻는다 — 새 내용이 빠지지 않게), 처음부터 다시 읽고 지도를 다시 낸다. 예전 지도는 `prev`로 두어 같은 이름 개념의 결과 · 범위 밖 표시가 이어진다(오답 노트도 이름으로 이어짐). 예전 판은 목록에서 사라진다.
- `study_room`이 지난번 연 뒤 바뀐 것을 `etl_changes`(new · revised · gone)로 돌려주고, 규칙(PLAYBOOK)에 "방을 열자마자 알린다"를 넣었다. 처음 여는 방은 알림 없음.
- 자료 = 파일 탭 · 페이지 탭 + 모듈의 파일 · 페이지 · 링크(ExternalUrl) · 외부 도구(ExternalTool). 과제 · 퀴즈 · 토론 · 소제목은 강의자료가 아니라 뺐다.
- eTL 페이지는 Claude를 부르지 않고 본문 HTML을 글로 바꿔(`15_activities.js`의 `plain` 재사용, 수식 그림 → LaTeX, 그림 → alt, 삽입 영상 → 주소 한 줄) 3000자쯤씩 '쪽'으로 준다. 하루 읽기 한도에 안 센다.
- 링크 · 외부 도구는 '못 읽음' → AI 앱이 직접 열어 읽거나 사용자가 내용을 채팅에 올리면 `by_client`로 지도, 아니면 범위 밖.
