## 확인한 파일과 처리 결과

- demo/timetable_boundary.json, demo/시간표_독립_기대값.md의 F01~F15, tests/test_end_to_end.py의 시간표 검사 작성 내용을 읽었다.
- docs/sessions/Frontend.md·docs/검증_결과.md·Frontend-07을 대조했다. 최초 13개 준비 뒤 경고 전파 검사를 더해 **신규 시간표 검사 14개**가 됐다.
- **Frontend 직접 실행 보고:** 기존 요건 검사만 12 passed, 14 deselected in 1.40s. 제외된 14개는 미실행이며 통과·완료로 세지 않는다.
- 새 14개는 Planner 통합 API 준비 통지 후 실행한다. 기존 전체250개 통과는 그때의 코드·검사 범위이며 새 시간표 기능 검증을 포함한다고 표현하지 않는다.
- 방향별 비용·집 출발/귀가·모든 회의 충돌·미정 이동·최대3안·예상학기·빈도창·탐색한도·경고 전파·링크 독립 해독은 검증 준비 범위다. 수작업 기대값을 실제 엔진 결과로 소개하지 않는다.
- Document는 파일·보고·검사 내용을 읽고 문서 연결을 확인했다. Frontend가 명시적으로 준비 통지를 기다리는 검사를 대신 실행하거나 전체 pytest를 반복하지 않았다.
