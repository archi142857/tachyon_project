# Concept의 통합 전 보조 검토

- 날짜: 2026-11-07
- 도구: Codex
- 기록 유형: AI 세션 간 지시·보고
- 발신·수신: Concept ↔ 읽기 전용 보조 검토자 2명
- 목적: 통합 커밋 전 공개 기록과 계산 정확성을 독립적으로 확인
- 검토 시점 이후 변경은 별도 최종 검사 대상입니다. 과거 모든 하위 검토 원문을 확보했다는 뜻은 아닙니다.

## 공개 포함 범위 검토 요청 원문

```text
이번 사용자는 현재 프로젝트 변경 커밋·푸시를 직접 요청했습니다. 저장소 D:\대학교\비교과\ChatGPT Edu 활용 상시 공모전\tt-wizard-gpt-edition. 현재 여섯 담당 세션이 첫 산출물 마무리 중이며 Concept만 통합 커밋합니다. READ ONLY로 AGENTS 및 변경 diff 확인 후 공개 저장소에 커밋하면 안 되는 실제 개인정보/인증정보/컴퓨터 경로 누출, 현재변경의 명백한 완료과장/깨진구조를 검토해 주세요. 전체 Git 추적/미추적 변경 중 특히 문서·프롬프트·demo·integrations 검사. 테스트가상자료를 실제유출로 오인하지 말고 필요한 증거만 보고. 코드소유자에게 직접 메시지/수정/커밋금지. 변경중이므로 검토시점 파일/문제한정 보고. git은 safe.directory와GIT_OPTIONAL_LOCKS=0 읽기.
```

## 공개 포함 범위 검토 최종 보고 원문

읽기 전용 검토 결과, 현재 변경에서 실제 학생 정보·인증정보·사용자 실명 경로는 발견하지 못했습니다. 가상 입력과 로컬 실행 결과의 구분도 유지돼 있습니다.

커밋 전 확인할 사항은 두 가지입니다.

- 새 프롬프트 3개에 내부 채팅·사용자 메시지 식별자가 포함돼 있습니다: `Backend-Integrations-02` 8·15행, `Document-03` 13행, `Research-02` 6·13행. 공개본에는 가림 사실을 명시하고 식별자를 제거하는 것이 적절합니다. Concept의 “앱 내부 대화 식별자는 공개 기록에 복제하지 않음” 기록과도 현재 불일치합니다.
- `demo/README.md`, `독립_기대값.md`, `사용_흐름.md`의 `docs/검증_결과.md` 링크 4개는 검토 당시 대상 파일이 없었습니다. Frontend 마감 후 생성 여부를 확인하면 됩니다.

개인 이름이 없는 기존 작업 경로는 새 개인정보 유출로 판단하지 않았습니다. `.pyc`는 제외 규칙 대상이고, 모의 연결에는 실제 학교 접속·발송 코드가 없습니다. README·현재 상태의 148개 테스트/2-C 미완료 표시는 최종 통합 시 갱신 대상입니다.

파일 변경·테스트·커밋은 수행하지 않았습니다.

## 계산 검토 요청 원문

```text
READ ONLY 코드 검토. 저장소 D:\대학교\비교과\ChatGPT Edu 활용 상시 공모전\tt-wizard-gpt-edition 의 신규 planner/requirements.py 및 tests/test_requirements.py, requirements_format.md, demo/run_local.py+tests/test_end_to_end.py가 커밋 준비 중입니다. AGENTS·data/requirements/README.md 계약 읽고 정확성 치명도 높은 오류 1~3개 있으면 재현근거로만 보고. 특히 확인필요85충족금지,부분조회/수강중/반복이수/다전공,전공대응과5명시목록. 파일작성중일수있고소유자완료아직대기. 소유자에게직접메시지나수정금지. 필요시독립읽기검증 가능,테스트임시dir .test-tmp/commit-review. git수정없음. 현재사용자커밋푸시승인했으나실행은Concept만. 결과원문은Concept가AI작업기록에보존.
```

## 계산 검토 최종 보고 원문

읽기 전용 검토에서 커밋을 막을 만한 정확성 오류는 발견하지 못했습니다.

- 고정 자료의 자동 계산 5항목·수동 확인 85항목 경계가 유지됩니다.
- 부분 입력, 수강 중, 반복 이수, 다전공 인정 불명, 미지원 전공·학번은 확정 충족으로 처리하지 않습니다.
- 원본·스키마·배포본 검증과 계산 필드 재생성이 적용돼 있습니다.
- 가상 시연은 로컬 실행이며 GPT·시간표 실행과 구분돼 있습니다.

직접 실행: `tests/test_requirements.py`와 `tests/test_end_to_end.py` **66개 통과, 3.76초**. 임시 경로는 `.test-tmp/commit-review`입니다. 파일 수정·커밋·푸시는 하지 않았습니다.

다음 담당: **Project / Concept — 통합 검증 및 커밋 진행 가능.** 검토 이후 파일이 변경됐다면 최종 대상에서 전체 테스트를 확인하면 됩니다.

## 후속 처리

Concept은 식별자 가림·개인 경로 확인·문서 링크와 목록 열 정리를 각 담당에게 요청했습니다. 검토 뒤 추가 생성된 파일도 최종 검사합니다. 관련 실제 전달은 [세션 간 실행 지시](Concept-AI-01-세션간-실행지시.md), 마감 결과는 [Concept 인수인계](../docs/sessions/Concept.md)와 [작업 기록](../docs/작업_기록.md)에서 확인합니다.
