# 공식 조사와 모의 연결 실행 배정

- 날짜: 2026-11-07
- 도구: Codex
- 담당: Project / Backend / Integrations
- 전달자: Project / Concept
- 출처 분류: **AI 세션 간 작업 지시**. 사용자의 말을 인용했어도 이 전달 메시지의 발신자는 AI다.
- 수신 담당: Project / Backend / Integrations
- 공개용 가림: 채팅·메시지 식별자를 `[내부 식별자 생략]`으로 대체했다. 그 외 원문은 보존했다.
- 목적: 공개 조사 결과를 실제 네트워크가 없는 모의 연결 코드·검증으로 연결한다.
- 승인 근거: Concept 채팅의 사용자 메시지 `[내부 식별자 생략]`를 읽어 같은 프로젝트 세션 간 자율 진행 지시를 직접 확인했다. 승인 근거와 이번 전달문의 작성 주체를 구분한다.

## 전달받은 실행 배정 원문

```text
사용자가 Project / Concept에서 “그 너네끼리 서로 명령하는 게 가능하면 그냥 알아서 진행하고 있으셈”이라고 직접 지시했습니다. 이번에는 규칙 확인 통지가 아니라 담당 작업의 실행 배정입니다. 작업 저장소: D:\대학교\비교과\ChatGPT Edu 활용 상시 공모전\tt-wizard-gpt-edition. 최신 AGENTS.md와 docs/작업_배정.md를 먼저 읽으세요. 기존 목표·담당 범위의 같은 프로젝트 세션 간 필요한 요청·결과 전달을 허용한 지시이며 커밋·푸시·외부발송·학교회신전 자동조회·실제공개 조건은 유지합니다.

사용자 승인 원문을 직접 확인해야 하면 read_thread로 hostId local, threadId [내부 식별자 생략]의 최신 turn에서 userMessage [내부 식별자 생략]를 확인하세요. 해당 사용자 지시에 근거해 필요한 담당에게 직접 질문·보고할 수 있습니다. 단순 수신확인 재전송 반복은 하지 마세요. 현재6개실행세션은 모두같은작업폴더이니 자기소유파일만수정하세요.

첫 실제 작업을 진행하세요. 최신 자동화/계획서 설계와 Planner의 transcript_format.md를 읽고 공식 공개 조회 경로를 조사해 docs/연동_조사.md에 출처·가능범위·미확인·조건을 정리하세요. 이어 실계정이나 라이브 조회와 분리된 표준 라이브러리 모의 연결 코드를 integrations/와 담당 tests에 만드세요. 학기·교과목번호·분반 키, 미확인/미등록/등록/조회실패, 마지막정상상태, 최초발견과 확인된미등록→등록 사건, 중복 방지, 알림끄기 유지, 부분조회·만료를 검증하세요. 실제 마이스누 자동 읽기·크롤링·정기 조회·외부 메시지 발송·Actions 연결은 하지 않습니다. Legal에게 기술 후보의 이용조건 검토 입력을 전달하세요. 실행 가능한 모의 테스트와 형식 문서를 남기고 전체 검증 후 Concept에 결과를 보고하세요. 코어 계산은 복제하지 마세요.
```
