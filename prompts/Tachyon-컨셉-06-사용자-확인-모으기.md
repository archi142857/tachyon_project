# Tachyon · 컨셉 06 · 사용자에게 필요한 것을 컨셉이 모아 알리기

- 날짜: 2026-11-09
- 도구: Claude (claude.ai 프로젝트 세션, Claude Opus 5.5), Google Drive 연결
- 기록 유형: 사용자 직접 지시
- 목적: 여러 세션과 팀원 쪽에서 사용자 권한·대답이 필요한 일을 한곳(컨셉)으로 모아 사용자에게 한 번에 알린다.

## 프롬프트 원문

````text
앞으로 내 권한이 필요하거나 내 대답이 필요한 것들은 모두 너가 다 모아서 나한테 알려줘.
````

## 결과 요약

규칙을 정했다: 각 세션은 사용자에게 바로 묻지 않고 컨셉 받은편지함에 `사용자-` 쪽지로 보낸 뒤 다른 일을 하고, 컨셉이 모아 claude.ai 프로젝트 문서 'Tachyon_사용자_확인'에 올린 뒤 사용자에게 한 번에 알린다. 팀원 쪽이 소통판에 사람에게 묻거나 부탁한 것도 컨셉이 모은다. 도구가 띄우는 권한 창은 예외. 이 규칙을 세션 운영 문서(레포 사본)와 프로젝트 문서 'Tachyon_작업_방식', 드라이브 쪽지 규칙에 넣고 세 세션에 쪽지로 알렸다. 지금 걸려 있는 일(Cloudflare 초대 수락, 자동 배포 연결, 비밀값 4개, 로그인 작업·Mac·Codex 제안에 대한 답, 공모전 공고 본문, eTL 메뉴 이름)을 한 목록으로 모아 사용자에게 알렸다.
