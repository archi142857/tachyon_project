# 00j. 컨셉 세션과 추가 세션 역할 분담

- 날짜: 2026-11-07
- 도구: Codex
- 목적: 현재 대화를 컨셉 세션으로 두고, 필요한 추가 세션의 담당 범위·시작 순서·복사할 프롬프트를 준비한다.

## 프롬프트 원문

````text
이 프로젝트 내에서 넌 컨셉 세션임 ㅇㅋ? 이제 더 필요한 세션이 뭔지 알려주고, 각각한테 입력할 프롬프트를 줘봐.
````

## 결과 요약

컨셉과 추가 역할 4개(A 자료·졸업요건, B 계산·시간표, C 학교 연동·알림, D GPT·시연·검증)를 나눴다. 각 역할의 첫 작업, 앞 작업에서 받을 자료, 직접 수정할 파일, 완료 기준과 보고 방식을 정했다. 공통 문서는 컨셉이 결과를 통합하고 각 세션은 자기 인수인계·프롬프트를 기록하도록 기존 지침에 명시적 예외를 추가했다.

시작 프롬프트는 제안본으로 보존했다. 사용자 소유의 새 채팅을 생성하거나 각 세션의 구현을 시작한 것은 아니다. 기능 구현 상태는 작업 1 완료로 유지했다.
