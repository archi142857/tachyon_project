# 프롬프트·작업 전달 기록

실제로 받은 지시·수정 요청·결과 보고를 출처별로 기록합니다. 현재 지침은 [AGENTS.md](../AGENTS.md), 실행 범위는 [인수인계 목록](../docs/sessions/README.md)을 봅니다. 과거 요청은 당시 기록이며 현재 정책을 대신하지 않습니다.

사용자의 말을 인용한 AI 전달도 **AI 세션 간 지시·보고**로 분류합니다. 요청·전송 성공은 구현 완료가 아닙니다. 공개에 필요 없는 개인 경로·내부 채팅/메시지 식별자는 각 기록에서 생략 표시로 가립니다. 세부 송수신 대상이 여러 명이면 본문별 기록을 따릅니다.
