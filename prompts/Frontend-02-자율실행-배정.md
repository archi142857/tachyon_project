# Frontend 자율 실행 배정

- 날짜: 2026-11-07
- 도구: Codex 세션 간 전달
- 목적: 첫 산출물 실행 및 Planner 통합 검증
- 출처 구분: **AI 세션 간 작업 지시**. 사용자 지시를 인용했지만 이 전달의 발신자는 Concept이다. 내부 채팅·메시지 식별자와 개인 경로는 아래 원문에서 가렸으며 나머지 문구는 보존했다.
- 권한 근거: Concept 채팅에서 사용자 원문 ‘그 너네끼리 서로 명령하는 게 가능하면 그냥 알아서 진행하고 있으셈’을 read_thread로 직접 확인했다. 아래는 사용자의 직접 입력이 아닌 Concept의 배정 원문이다.

## 받은 배정 원문

```text
사용자가 Project / Concept에서 “그 너네끼리 서로 명령하는 게 가능하면 그냥 알아서 진행하고 있으셈”이라고 직접 지시했습니다. 이번에는 규칙 확인 통지가 아니라 담당 작업의 실행 배정입니다. 작업 저장소: [개인 경로 생략]/tt-wizard-gpt-edition. 최신 AGENTS.md와 docs/작업_배정.md를 먼저 읽으세요. 기존 목표·담당 범위의 같은 프로젝트 세션 간 필요한 요청·결과 전달을 허용한 지시이며 커밋·푸시·외부발송·학교회신전 자동조회·실제공개 조건은 유지합니다.

사용자 승인 원문을 직접 확인해야 하면 read_thread로 hostId local, threadId [내부 식별자 생략]의 최신 turn에서 userMessage [내부 식별자 생략]를 확인하세요. 해당 사용자 지시에 근거해 필요한 담당에게 직접 질문·보고할 수 있습니다. 단순 수신확인 재전송 반복은 하지 마세요. 현재6개실행세션은 모두같은작업폴더이니 자기소유파일만수정하세요.

첫 사용 흐름·검증 준비 작업을 진행하세요. 실제 GPT 사용면을 기준으로 가상 학생 3사례 입력, 취득/수강중/미확인 확인표, 남은요건/확인필요/시간표미준비 결과 표시 흐름을 설계하고 demo/ 및 docs/검증_결과.md에 독립 수작업 기대값·검증표를 만드세요. gpt/지침·설명·시작문구는 초안임을 명시해 만들 수 있습니다. Planner 2-C가 진행 중이므로 결과형식을 협의하고 완료되면 이를 사용해 통합 검증을 하세요. 기다리는 동안 기본입력확인과 수작업 검증은 진행하세요. 별도 웹서비스나 미구현 계산 화면을 완성작처럼 만들지 말고, 실제 GPT 공개·빌더 변경은 하지 마세요. generated knowledge/build_gpt.py는 Planner 소유입니다. 계산 출력을 정답으로 복사하지 말고 오류는 재현 입력으로 Planner에 직접 보내세요. 완료한 산출물과 실제/모의/미구현 구분을 Concept·Document에 전달하세요.
```

결과: 가상 3입력, 붙여 넣기 표, 사용 흐름, 독립 기대값, 로컬 실행기와 결과 JSON, 통합 검사12개. 전체246개+하위검사9개 통과. [인수인계](../docs/sessions/Frontend.md)와 [검증 결과](../docs/검증_결과.md)를 따른다. GPT 설정·실제 빌더는 변경하지 않았다. 화면 캡처 없음.
