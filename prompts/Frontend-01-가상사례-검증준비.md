# Frontend 첫 요청: 가상사례와 검증 준비

- 날짜: 2026-11-07
- 도구: Codex
- 목적: GPT 기본 사용면의 가상 3사례와 독립 검증 기준 준비
- 출처 구분: **사용자 직접 지시**. 아래 원문에는 공개용 가림 처리가 필요한 값이 없다.

## 사용자 원문

```text
너는 ‘Project / Frontend’ 세션이다.
작업 저장소는 현재 프로젝트 안의 tt-wizard-gpt-edition이다.

docs/세션_프롬프트/Frontend.md를 이번 작업의 상세 지시로 읽고 따라라.
첫 작업은 가상 학생 3사례의 입력부터 결과 비교까지 사용 흐름과 독립적인 검증 기준을 만드는 것이다.
현재 기본 사용면은 GPT다. 별도 웹사이트를 임의로 만들지 말고, 계산 기능이 준비되면 실제 GPT 연결·결과 표시·통합 시연을 진행한다.

없는 기능은 설계·모의로 표시하고 계산 결과를 임의로 만들어 내지 마라.
결과와 다음 과제를 docs/sessions/Frontend.md에 남겨라.
커밋·푸시는 하지 마라.
```

## 결과와 정정

최초 응답에서는 산출물을 만들지 못했다. 저장소 접근 권한 문제라고 설명한 것은 잘못이며, 상위 작업 폴더에서 상대 경로를 잘못 지정한 것이었다. 실제 저장소 읽기는 성공했었다. 후속 응답에서 이를 정정했고, 자율 실행 배정 후 산출물과 실제 검증을 완료했다.

결과: [Frontend 인수인계](../docs/sessions/Frontend.md), [가상 시연 자료](../demo/README.md), [검증 결과](../docs/검증_결과.md). 실제 GPT 화면 캡처는 없고, 계산 결과는 로컬 실행 기록이다. 다음 작업은 인수인계를 따른다.
