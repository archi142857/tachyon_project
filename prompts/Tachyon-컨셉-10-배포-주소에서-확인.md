## 결과 요약

- 의견 버튼 글이 GitHub 이슈 #2가 된 것을 확인했다: 라벨 '의견·버그', 화면·시각·기기·'사용자 #2'가 자동으로 붙음. 기기는 Windows · Chrome이라 PC에서 보낸 것.
- 계획: 의견 버튼 줄 `[x]`, 구글 로그인 줄(로그아웃 확인 남음)과 즉시 팝업 줄에 확인 메모. 폰 '홈 화면에 추가'(PWA 줄)는 기종을 사람에게 물음.
- 이슈 #2(사람의 시험 글)는 컨셉이 닫으려다 권한 확인에 막혀 그대로 두고 사람에게 물었다.
- 소통판에 알림, 팀원 쪽에 원격 `log` 줄 확인을 부탁했다.
