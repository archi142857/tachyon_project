# Tachyon · 디자인 05 · 로고·아이콘 시안(입자가 오른쪽으로 가며 자취를 남김)

- 날짜: 2026-11-11
- 도구: Claude (claude.ai 채팅, Claude Opus 5.5). 사람이 붙인 그림(팀원 시연의 'Tachyon' 머리 — 빛줄기 + 글자)을 보고, 저장소의 시연 9판(`docs/tachyon/디자인/참고/팀원_시연/시연-PC.html`)에서 그 모양(`.logo::before` 22×5 빛줄기)을 확인. 로고 모양은 작업 공간의 Python으로 SVG를 만들고(글자는 Jost 600을 npm `@fontsource/jost` 5.3.0에서 받아 fontTools·uharfbuzz로 선으로 바꿈), Python Playwright + 헤드리스 Chrome으로 미리보기를 찍어 봄. 시안은 Artifact 도구의 Design 형식으로 새 캔버스.
- 기록 유형: 사용자 직접 지시
- 목적: Tachyon 심볼·아이콘을 만든다. 팀원 시연의 움직이는 입자 같은 로고를 바탕으로, 입자가 오른쪽으로 가며 궤적을 남기는 모양.

(11-11 23:52, 그림 한 장 붙임: 검은 바탕에 보랏빛 빛줄기와 흰 'Tachyon' 글자)

````text
타키온 심볼, 아이콘 뭐 이런 거 만들어 봐. 그 다른 작업자가 했던 거 중에 입자가 움직이는 듯한 로고 비스무리한 게 있던데 그거 좋아보임. 그거 바탕으로 입자가 오른쪽으로 움직이는듯한, 궤적이 남는 그런 로고 만들어 봐.
````

## 결과 요약

- 캔버스: [Tachyon 로고 시안](https://claude.ai/artifact/Ni199KuYxKQBMVSS7hEvUv) — 네 가지. 보드마다 밝은·어두운 바탕의 로고(마크 + 글자), 앱 아이콘(512 타일), 작은 크기(60·32·16), 앱 안 왼쪽 메뉴 머리(실제 크기), 움직이는 판(앱을 여는 화면용, 동작 줄이기를 켜면 멈춤).
  - A 빛 꼬리: 팀원 빛줄기를 뒤집어 머리가 오른쪽. 꼬리는 왼쪽으로 옅어지는 쐐기, 머리는 빨강(앱의 '지금' 색). 입자(보라) 판도 같이.
  - B 점과 선: 칸딘스키의 점과 선. 빨간 점 + 뾰족해지는 검은 선, 번짐 없음.
  - C 점 자취: 지나온 자리에 작아지는 점(하루 고리의 입자).
  - D 고리 궤적: 하루 고리 꼭대기의 '지금'이 시계 방향(오른쪽)으로 가며 호를 남김.
- 공통: 머리 = 빨강 #c4321e(어두운 바탕 #ff5545), 꼬리·글자 = 먹. 글자는 Jost 600(SIL OFL 1.1)을 선으로 바꿔서 글꼴이 없어도 같다. 앱 아이콘은 꼬리를 줄여 16px에서도 머리가 보이게 했다.
- 고르기는 사람 몫. 고르면 아이콘 파일(icon.svg · maskable · 192 · 512 · apple-touch)을 만들어 화면 세션에 넘긴다(디자인 세션은 web/을 고치지 않는다).
