일단 지금은 어디까지 됐고 앞으로 뭘 더 해야하지?

## 결과 요약

AGENTS.md에 매 작업의 누적 현황·다음 과제 보고와 현황 문서 갱신 규칙을 추가했다. `docs/현재_상태.md`를 기준 문서로 만들고 읽을 순서, 구현 근거, 미구현 범위, 다음 산출물과 완료 기준을 정리했다. README와 졸업요건 안내에서 이 문서로 연결했다.

자료 생성·검증만 구현됐음을 확인했다. 기존 작업 공간의 2025학번 졸업요건 초안 7묶음을 발견했지만 현재 저장소에는 미반영이므로, 다음을 ‘작업 2-A: 기존 초안 검증·반영’으로 정했다. 실제 로그인·추천·알림은 완료로 표시하지 않았다.

GitHub `main`과 로컬 기준 커밋이 `8aca914c860496d5c6637292653e0b918ddaff2d`로 같음을 확인했다. 이번 현황 문서는 로컬 변경이며 커밋·푸시하지 않았다.
