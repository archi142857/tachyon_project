# 작업 3 독립 검증 준비

2026-11-07 · 기준 커밋09b4ecf. **계산 실행 전 고정한 수작업 기대값**이며 실제 GPT·실제 강좌 추천 결과가 아니다. [기존 기준](독립_기대값.md)의 T01~T08을 집→수업→집 전체 경로와 API 계약에 맞춰 구체화한다. 통과 여부는 `docs/검증_결과.md`의 후속 실행 기록에서만 확인한다.

입력은 [timetable_boundary.json](timetable_boundary.json)이다. A/B는 각각3학점인 모의 과목이고 월요일에만 수업한다. 요건자료1.0은 바꾸지 않으며 두 과목은 사용자가 시간표에 넣도록 지정한 후보다. 선수 이수 가능·졸업 인정의 근거는 아니다. 이동표200→302는24.66분, 역방향은18.28분을 실제 로컬 `data/walk.csv`와 대조했다. 집은200동으로 명시하며 건물 내부 이동은 이 계산에서0분이다.

| F01 방향 정방향 | 집200, A200 09:00~10:00, B302 10:20~11:20 | 집→A0 + A→B24.66 + B→집18.28 =42.94분. 수업 사이 여유−4.66·부족4.66. 비용42.94+2×4.66=52.26. 유효안1개 |
| F02 방향 역방향 | A302, B200, 나머지 동일 | 집→A24.66 + A→B18.28 + B→집0=42.94. 수업 사이 여유1.72·부족0. 비용42.94. 정방향보다 비용9.32 작음 |
| F03 맞닿은 시간 | B시작10:00·종료11:00 | 시간 겹침0. 이동여유−24.66·부족24.66. 비용42.94+49.32=92.26. 이동 부족으로 조합을 시간충돌 제외하면 실패 |

F11에서는 preferences.target_year=2(권장학년)를 함께 설정해도 개설빈도 창이2022~2026으로 유지돼야 한다. 이 기대값은 대상학기 달력연도와 권장 학년을 분리한 계약에 따른다.

링크 검사는 계산기의 decode 함수를 정답으로 사용하지 않는다. 표준라이브러리로 URL의 `t` 값을 직접 base64url 해독하고, z 형식이면 raw deflate 해제 후 JSON을 읽는다. `[1, source_term, title, [[code,section,null,name],...]]`과 실제 반환된 과목·분반 목록이 같아야 한다. 실제 지도 웹페이지 열림은 별도 미검증이다.

숫자 비교 오차는0.01분 이하이며 상태·학기·과목·분반의 일치에는 오차를 허용하지 않는다. 전체 비용에는 집 출발·귀가를 포함한다. 이번 기대값은 기존 T06의 ‘두 연강 구간만 합산’과 포함 범위가 다르다.
