# 예시 자료와 시연

2026-11-07. **예시: 실제 학생 자료가 아닙니다.** 가상 3사례의 구조화 입력·붙여 넣기 표·대화 설계·수작업 검증 기준을 준비했습니다. 로컬 계산 기록과 실제 GPT 실행은 구분합니다. PDF 예시와 실제 GPT 응답 캡처는 아직 없습니다.

`results/`는 로컬 Python 실행 기록이며 GPT 응답·화면이 아닙니다. 입력·사용 코드·자료의 SHA256은 results/manifest.json에 기록합니다. 현재 실제 GPT 적용 여부와 공개 여부는 이 기록만으로 확인할 수 없습니다.

작업3 시간표 독립 검사는14개를 더해26개 통합검사가 통과했습니다. 시간표 결과는 모의 강좌를 이용한 경계 검사이며 실제 학생3사례에 대한 수강 추천 완료나 지도 웹페이지 열림을 뜻하지 않습니다. 모의 강좌의 TT 링크는 형식·내용 복원만 검사했습니다.

학생이 만든 비공식 도구예요. 졸업 사정은 학과와 마이스누에서 최종 확인하세요. 다른 사람의 성적표는 올리지 마세요.
