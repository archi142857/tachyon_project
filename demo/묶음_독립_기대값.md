# 오프라인 묶음 독립 기대값

2026-11-07. **예시: 학생 입력과 조건은 전부 가상이다.** 아래 기대값은 묶음 실행 전에 입력 행·Research 1.0·제공 편람·방향별 이동표를 읽고 고정했다. 기존 엔진과 결과가 같다는 검사와 독립 산술 검사를 분리한다. 실제 GPT·실제 학생 추천·지도 페이지 검증이 아니다.

목표학기는 2027-1인 묶음을 사용한다. 목표 편람은 없고 2026-1을 예상 자료로 사용한다. 기본 3사례의 입력은 [inputs](inputs/)이며 앞선 [요건 독립 기준](독립_기대값.md)을 유지한다.

## 수작업 근거

- `data/offerings/2026-1.json`: `M2177.008600` 인공지능 개론, 3학점, 분반001, 금요일 810~980분(13:30~16:20), 302동 1호.
- 같은 편람: `5202.405` 공간경제모형론, 3학점, 분반001, 금요일 900~1070분(15:00~17:50), 200동 1007호.
- 두 과목의 유일한 분반은 금15:00~16:20, **80분 겹친다**. 두 과목 모두 필수면 6학점의 유효 시간표가 없다.
- `data/walk.csv`: 200→302는24.66분, 302→200은18.28분. 앞 과목 하나를 집200에서 왕복하면 **42.94분**이며 수업 사이 이동이 없으므로 부족0·비용42.94다. 서로 같은 확정 건물302에서 왕복이면0분이며 실내 이동은 포함하지 않는다.
- 인공지능 개론은 제공된 봄 편람 중2024·2025·2026년에 있고2022·2023년에는 없다. 직전5년 자료 파일은 모두 있으므로 개설3년·관측5년·자료 누락0년이다. 개설확률60%라는 뜻이 아니다.

## 검증 종류를 구분한다

1. **독립 기대값:** 위 숫자·상태·방향·시간 충돌·링크를 검사한다.
2. **동일성:** 같은 입력과 전체 편람·이동표를 기존 모듈에 전달한 transcript/requirements/candidates/json/markdown이 묶음과 같은지 비교한다. 이는 포장 과정의 보존 검사이며 독립 계산 정답을 추가로 입증하지 않는다.
3. **격리 실행:** 저장소 밖 새 폴더의3파일만 사용하고 `-I -S`로 실행한다. 입력은 표준입력, 가짜 PYTHONPATH 모듈은 가져오면 실패하도록 두며 실행 전후 파일 목록·해시를 비교한다. 실제 실행에서의 잔여 파일 확인이며 ChatGPT 서버 미보관 증거가 아니다.
4. **거부 동작:** 복사본의 manifest 누락·변조를 검사한다. 고정 오류·종료2와 입력/개인경로/traceback 비노출을 확인한다. 내부 ZIP 안전성·socket 차단·생성 재현성의 넓은 검사는 Planner의 별도 검증 근거를 참조하고 직접 실행한 범위를 구분한다.

[합성 시간표 F01~F15](시간표_독립_기대값.md)의 한 방향 누락·임의 미정 건물·두 번째 회의 겹침 등은 원래 모듈 경계검사로 유지한다. 고정 전체자료 묶음을 고쳐 이런 상황을 만들지 않는다. `run()`은 외부 편람·이동표 주입 API가 아니다.

실행값과 파일 해시는 [묶음 실행 기록](bundle_verification.json)에 따로 보존한다. 이 문서는 실행값을 보고 기대값으로 바꿔 쓰지 않는다.
