# 가상 3사례와 독립 기대값

2026-11-07 · Frontend 작성. **예시·수작업 검증 기준이며 실제 GPT 응답이나 학생의 졸업 판정이 아니다.** Planner 실행 전에 규정 목록, 입력 행, 산술을 보고 기대값을 정했다. 실제 실행 기록은 [검증 결과](../docs/검증_결과.md)에서 따로 관리한다.

## 입력의 출처와 범위

`inputs/`의 이수 상태·전공 조합·입력 범위는 지어냈다. 과목번호·과목명·학점·개설 학기는 저장소 `data/offerings/2025-1.json`, `2025-2.json`, `2026-1.json`, `2026-2.json`과 대조했다. 과거 학기를 수강 중으로 설정한 행은 상태 처리 검증을 위한 의도적인 가정이며 실제 현재 수강 상태를 뜻하지 않는다. 교수·성적·학생 식별자는 없다.

상태가 누락된 행을 취득 완료로 바꾸지 않는다. 입력의 학점 소계는 졸업 인정 학점이 아니다. 세 사례 모두 전체 이력 확인이 안 되어 전체 미이수와 졸업 가능 여부를 확정할 수 없다.

| 사례 | 취득/수강 중/미확인 행 수 | 확인된 취득 학점 | 확인된 수강 중 학점 | 취득 완료지만 합산 보류한 행 | 수작업 이유 |
| --- | --- | --- | --- | --- | --- |
| animal | 1 / 1 / 1 | 3 | 3 | 0 | 3학점 취득 1행만 취득분에 포함. 상태 누락 3학점은 미확인 |
| biology_double | 1 / 1 / 1 | 2 | 2 | 0 | 실험1 취득 2, 실험2 수강 중 2, 특수연구1 미확인 1 |
| chemical_double | 2 / 1 / 1 | 3 | 0 | 1 | 분석화학 두 행은 반복이므로 둘 다 보류. 물리화학2만 3. 응용생화학2는 미확인 |

## 요건별 기대 결과와 근거

기준 자료는 Research `data/requirements/2025.json`의 `schema_version=1.0`과 검토 기록이다. 90항목 중 85항목은 확인 필요로 유지한다. 5개 승인 목록도 개별 목록 대조만 가능하며 전체 졸업·전공 간 중복 인정 승인이 아니다.

| 검증 ID | 입력/조건 | 독립 기대 결과 | 근거/확인 범위 |
| --- | --- | --- | --- |
| R01 | animal | 동물생명 주전공 요건은 확인 필요. 남은 졸업학점 숫자 생성 금지 | `animal-main`의 모든 항목이 manual_review. Research 검토를 인용하며 학과 규정을 새로 확정하지 않음 |
| R02 | biology_double | `biology-double-R05` 취득 관측분 1과목·2학점. 실험2와 특수연구1을 충족으로 세지 않음. 상태 미확인·부분입력으로 판정 보류 | [생명과학부 교과과정](https://biosci.snu.ac.kr/academics/curriculum/undergraduate), 2025~2026학번 복수전공 전선(필수). 실험1·2·특수연구1 세 과목, 2+2+1=5 |
| R03 | R02에서 특수연구1을 취득으로 정정 | 취득 소계 2+1=3, 수강 중 2. 5−3=2는 목록상 관측 부족분이며 부분 이력의 확정 미이수로 표시하지 않음 | 같은 공식 목록과 입력 상태. 수정 후 재계산 필요 |

| R05 | 별도 경계 입력: 생명과학부 주전공 하나, 전체라고 명시, 세 과목 모두 취득 | `biology-main-R06` 단일 항목 충족 가능(3과목·5학점). 나머지 요건 확인 필요 | 같은 공식 문서 주전공 전선(필수). 단위 경계 입력이며 네 번째 학생 시연으로 세지 않음 |
| R06 | R05에서 실험2를 수강 중으로 변경 | 확인된 취득 3, 수강 중 2. 이 단일 요건 남음: 실험2 1과목·2학점. 수강 중은 취득 예정일 뿐 | 이수내역 v1의 상태 규칙과 공식 필수 목록 |
| R07 | chemical_double | 화생 복수전공 요건 확인 필요. `chemical-main-R03/R04/R05`를 부과하면 실패 | Research 화생 복수전공 항목은 자동 계산 승인 없음. 주전공 승인 목록을 복수전공으로 복제 금지 |

| R10 | 동물생명·화생의 미확인 선수관계 또는 권장 학년만 존재 | 확인 필요. 권장 학년·학기를 의무 선수조건으로 바꾸지 않음 | `animal-main-C05`, `chemical-double-C04`, Research 검토 |

생명과학 공식 두 웹 문서는 Frontend가 2026-11-07 재조회했다. 웹 문서 전체를 복제하지 않고 위 적용 부분만 요약했다. 학점 및 과목번호는 Research의 과목안내 대조와 로컬 편람도 함께 확인했다. 화생·동물생명 규정의 전면 재검증은 수행하지 않았다.

## 시간표·동선: 수작업 기준만 준비, 엔진 실행 전

아래 수업 A/B는 실제 강좌가 아닌 **모의 시간 구간**이다. 이동값만 현재 `data/walk.csv`의 방향별 행을 사용한다. 시작·끝은 같은 요일이며 경계 시간은 반열린 구간으로 비교한다. 실제 추천 결과나 측정한 보행 시간이 아니다.

| 검증 ID | 모의 입력 | 수작업 기대값 |
| --- | --- | --- |
| T01 | 월 A 09:00~10:00, B 09:50~11:00 | 겹침 10분. 같은 조합 추천 불가 |
| T02 | 월 A 09:00~10:00, B 10:00~11:00 | 겹침 0분. 이동 여유는 별도 계산; 겹침이 없다고 이동 가능이라 하지 않음 |
| T03 | 월 200동 수업 10:00 종료 → 302동 10:20 시작 | 간격 20분, 이동 24.66분, 여유 20−24.66=−4.66분. 빠듯함 4.66분; 시간 겹침으로 부르지 않음 |
| T04 | 월 302동 수업 10:00 종료 → 200동 10:20 시작 | 간격 20분, 이동 18.28분, 여유 1.72분. 역방향 값을 복제하면 실패 |
| T05 | T03의 두 번째 강의실 미정 | 이동·여유는 미확인. 계산 비용에서 제외되더라도 화면에 ‘0분/이동 가능’ 표시 금지 |
| T06 | 모의 한 주에 T03·T04 각 한 번, 출발·귀가 제외 | 확인된 두 이동 합계 24.66+18.28=42.94분. 전체 주간 걷기 합계로 확대 금지; 출발·귀가 포함 범위 명시 |
| T07 | 편람 미확보 다음 학기 | 정확히 전년도 같은 학기 편람 사용 시 ‘예상’, 기준 학기 명시. 전년도 자료도 없으면 더 오래된 편람으로 조용히 대체하지 않음. 과거 강좌를 미래 확정으로 표시하면 실패 |
| T08 | 조건에 맞는 조합 1개 또는 0개 | 실제 개수와 부족 이유를 표시. 3안을 채우려고 과목·분반·시간을 생성하면 실패 |

허용 오차는 이동 소수 표시 반올림에만 0.01분이며 판정 부호·과목번호·상태에는 오차를 허용하지 않는다. T01~T08의 엔진 검증은 시간표 API가 준비된 뒤 진행한다.

작업3 계약을 받은 뒤 집 출발·귀가를 포함한 세부 수작업 기준을 [시간표 독립 기대값](시간표_독립_기대값.md)에 추가했다. 별도 모의 입력이며 기존 가상3학생의 실제 추천 결과가 아니다.
