# 스누지니를 기준으로 한 구현 목표

**스누지니에서 확인한 기능 범위를 빠짐없이 관리하고, 개인별 졸업요건과 실제 분반의 시간·이동 조건을 함께 계산하는 것을 목표로 합니다.** 추천 이유, 충족하는 요건, 시간 겹침, 이동 여유, 선택을 바꿨을 때의 영향을 학생이 확인할 수 있게 만듭니다.

- 정리일: 2026-11-06
- 현재 상태: 구현 목표와 검증 기준을 정리한 단계입니다. 이 문서의 목표 기능은 구현 완료가 아닙니다.
- 비교 근거: [스누지니 조사](스누지니_조사.md)의 B01~B18. 출처의 시기와 학교 자료·업체 발표 구분은 조사 문서를 따릅니다.
- 현재 구현: 강좌·건물·이동시간 자료 생성과 검증. 나머지 최신 진행 현황은 [현재 상태](현재_상태.md)를 봅니다.

스누지니의 대화형 탐색·개인화·학업 로드맵도 비교 범위에 포함합니다. 이러한 기능을 계획했다는 사실만으로 더 우수하다고 주장하지 않습니다. 이 문서는 우리가 만들 동작과 완료 기준을 정의하며, 실제 우위는 구현 뒤 같은 조건으로 측정해야 합니다.

## 우선순위와 단계

| 표시 | 의미 | 연결할 작업 |
| --- | --- | --- |
| 핵심 계산 | 남은 요건과 실제 시간표를 계산하기 위해 먼저 만드는 부분 | 기존 작업 2·3, 대화와 결과 연결은 작업 4, 검증·시연은 작업 5 |
| 범위 확장 | 세 전공 시범 이후에도 스누지니의 확인된 범위를 빠뜨리지 않기 위한 부분 | 핵심 계산이 작동한 뒤 별도 확장 작업으로 나눔 |
| 학교·자료 연결 필요 | 자료·연결·권한이 확보돼야 실제로 동작하는 부분 | 관련 확인과 모의 검증은 병행하고, 실제 연결은 확인 후 진행 |

아래 표의 ‘완료 기준’은 앞으로 충족해야 할 조건입니다. 모든 목표는 현재 미구현이며, 기존 자료 생성 코드를 일부 입력으로 사용할 수 있을 뿐입니다. 학교·자료 연결 필요 표시는 전체 프로젝트를 멈춘다는 뜻이 아닙니다.

G19는 기존 TT Wizard의 비교식을 유지합니다. **비용 = 한 주 걷는 시간 + 2 × 이동 여유가 부족한 시간**입니다. 시간 겹침은 불가이고, 빠듯한 이동은 부족 시간을 비용에 더하고 결과에 표시합니다. 방향별 시간을 대칭으로 바꾸지 않습니다. 강의실 미정 구간은 이동 계산에서 제외하되 실제 이동 0분이나 도착 가능으로 설명하지 않습니다. 공식 수업시간 자체가 불명확하면 시간 겹침이 없다고 확정하지 않습니다.

수업 이동은 계산된 시간의 추정입니다. 실제 보행 속도·혼잡·공사 등을 검증하지 않은 상태에서 도착을 보장하지 않습니다. 다음 학기 편람이 없으면 지난 같은 학기의 분반으로 ‘예상’ 시간표를 만들고, 과거 개설 이력과 다음 개설 확정을 구분합니다.

시간·이동 조건을 만족해도 실제 수강신청 성공을 뜻하지 않습니다. 정원·수강 자격·폐강대상 등 공식 상태를 별도로 확인하고, 없는 정보는 미확인으로 표시합니다. 학교 장바구니나 신청 상태를 우리 시간표 선택만으로 변경했다고 표현하지 않습니다.

G21의 등록 감지는 계획서가 새로 확인됐다는 사건입니다. G11의 비교과 알림은 확인된 신청 일정에 따른 사건입니다. 둘의 대상·기준 시각·중복 방지 기록을 따로 관리합니다. 자세한 상태 판정은 [강의계획서 모아보기와 알림](강의계획서_모아보기와_알림.md)을 따릅니다.

G11은 프로그램 전체를 구독해 새 일정마다 알림을 받는 경우와, 선택한 일정 하나에만 알림을 받는 경우를 구분합니다. 한쪽만 구현한 상태를 B11의 전체 범위 충족으로 세지 않습니다.

## 데이터가 없으면 채웠다고 표시하지 않습니다

- **첫 시범 범위:** 2025학번 동물생명공학전공·생명과학부·화학생물공학부의 주전공·복수전공과 공통 교양입니다. 이 범위를 구현해도 학교 전체에 대한 스누지니와의 동등 범위를 달성한 것은 아닙니다.
- **공개 개설 이력:** 어떤 학기에 어떤 분반이 열렸는지입니다. 학생이 실제 들은 과목, 학년별 수강 통계, 선배의 학업 경로를 뜻하지 않습니다.
- **선배·유사학생 자료:** 현재 저장소에 없습니다. 별도 자료를 확보하지 않은 상태에서는 G08의 해당 추천 근거, G16의 실제 선배 비교, G17의 학생 수강 통계를 미충족으로 유지합니다. 합성 예시는 반드시 모의 데이터로 표시합니다.
- **교수 정보:** [AGENTS.md](../AGENTS.md)의 교수 이름 제외 규칙을 유지합니다. G07·G18은 해당 정책을 결정해야 하는 항목이며, 조사를 이유로 교수 명단이나 연구 실적 개인별 자료를 수집하지 않습니다.
- **성적·학습케어:** 취득 완료·수강 중 구분은 공식 이수 상태로 처리합니다. 성적 점수 없이 만들 수 있는 이수 안내를 학습케어 대상 판정과 같다고 보지 않습니다.
- **학교 연결·신청:** 마이스누 자동 조회의 정보화본부 회신 조건, GPT Actions 별도 결정을 유지합니다. 학교 신청 제출·교직원 통보 기능은 권한과 절차가 별도로 확인돼야 하며 현재 수행 범위에 없습니다.
