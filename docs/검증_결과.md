## 실제 가상 3사례 결과

실행기로 저장한 계산값이다. ‘확인 필요 항목 수’에는 선택된 전공과 공통 참고 묶음만 포함하며, 학교 전체나 전체 90항목 수가 아니다. 공통 교양은 소속·입학경로가 미확인인 참고 묶음이다.

| 예시 | 취득/수강 중/미확인 행 수 | 확인된 취득 / 수강 중 학점 | 합산 보류 취득행 | 충족 / 남음 / 확인 필요 항목 | 결과 |
| --- | --- | --- | --- | --- | --- |
| 동물생명 2학년 | 1 / 1 / 1 | 3 / 3 | 0 | 0 / 0 / 24 | [실행 JSON](../demo/results/animal.json) |
| 생명과학 복수전공 | 1 / 1 / 1 | 2 / 2 | 0 | 0 / 0 / 37 | [실행 JSON](../demo/results/biology_double.json) |
| 화학생물공학 복수전공 3학년 상황 | 2 / 1 / 1 | 3 / 0 | 1 | 0 / 0 / 32 | [실행 JSON](../demo/results/chemical_double.json) |

세 사례 모두 `graduation_status=not_evaluated`다. ‘남음 0항목’은 남은 졸업요건이 없다는 뜻이 아니다. 확인 필요여서 확정 판정이 보류된 것이다.

생명과학 복수전공 `biology-double-R05`는 취득 관측 1과목·2학점, 수강 중 실험2, 미확인 특수연구1로 반환됐다. `observed_deficit`은 2과목·3학점이지만 `remaining=null`이다. 화면에서는 확정 남은 학점으로 옮기지 않는다. 화생 주전공 승인 항목은 화생 복수전공 결과에 포함되지 않았다.

별도 수정·경계 검사에서는 특수연구1 취득 정정 후 3학점, 실험2까지 취득 정정 후 5학점을 확인했다. 일부 입력·다전공 상태는 계속 확인 필요다. 생명과학 주전공 하나와 전체라고 명시한 가상 경계 입력에서는 단일 목록이 5학점일 때 충족, 실험2가 수강 중이면 2학점·1과목 남음으로 반환됐다. 전체 졸업 상태는 계속 미판정이다.

## 검증 방법과 결과

기대값은 [독립 기대값](../demo/독립_기대값.md)에 Planner 실행 전에 고정했다. 계산 출력에서 기대값을 생성하지 않았다. 보조 검토에서 Research 승인 5목록·적용 전공·학점·수동 항목 경계를 따로 확인했다. Frontend는 생명과학 공식 교과과정과 2025-01-10 공지를 재조회했고, 다른 학과의 공식 규정을 전면 재검증하지 않았다.

일반 Python 환경:

```powershell
python -m pytest tests/test_end_to_end.py -q
python demo/run_local.py
python -m pytest -q
```

실행 결과:

- Frontend 통합 검사: **12 passed, 2.23초**, 건너뛴 검사 없음.
- 전체 검사: **246 passed, 9 subtests passed, 7.11초**. 동시 작업 시점의 Planner·Research·Integrations 검사도 포함. 실제 학교 규정 전체 확정이나 GPT 동작을 입증하는 수치가 아님.
- 가상 3사례 로컬 실행: 모두 `requirements_state=executed`. `timetable_state`와 `gpt_state`는 `not_executed`.
- 담당 변경의 `git diff --check`: 오류 없음.
- 재현 가능한 계산 불일치: 이번 12개 통합 검사에서 발견하지 못함. 테스트 바깥의 정확성을 보장하지 않음.

이 환경에서는 기본 Python 경로가 없어 앱의 Python 3.12.14를 사용했다. 기존 다른 담당 테스트 도구 폴더는 접근이 제한되었고, 일반 실행의 패키지 다운로드도 막혀 첫 테스트 시도가 실패했다. 승인된 실행으로 Frontend 전용 임시 폴더에 요구사항 범위의 pytest 9.2.0을 설치하고 같은 권한으로 재실행해 위 결과를 얻었다. 계산 코드 오류와 환경 실패를 구분한다. 저장소 의존성 파일은 변경하지 않았다.

실제 통과 명령의 공개용 표기다. 개인 이름이 포함된 임시 경로는 아래 `<사용자 임시 폴더>`로 가렸다. 실행하려면 이 표시를 해당 환경의 임시 폴더로 바꾼다.


실행 당시 입력·자료·계산 코드 해시는 [manifest](../demo/results/manifest.json)에 있다. 다시 실행하면 고정 가상 사례 기록이 갱신된다. 실제 학생 입력을 이 실행기에 추가하지 않는다.
