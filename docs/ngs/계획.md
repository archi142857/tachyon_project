## 회의에서 정한 것 → 계획에 넣은 방식

| 회의 | 계획 |
|---|---|
| 웹 먼저, 서버 기반 | PWA 하나. 폰·PC·패드가 같은 주소, 서버 DB라 기기 간 동기화 걱정 없음 (옵시디언 파일 동기화 문제 해결) |

| 메인 루프 = 캘린더 + 밀도 | 할 일 3개 = 여유가 적은 순. 몰린 주는 경고. '지금 시작 가능 / 수업·자료 뒤' 표시 |
| 대시보드는 적게 | 할 일 3개 · 주간 달력 · 메모만. 나머지는 햄버거 메뉴 |
| 챗봇 대신 '정리되는 나와의 채팅' | 일정처럼 보이는 글 → 즉시 팝업(시간·이름·장소 → 저장). 나머지는 밤에 정리 |
| AI가 일을 부풀린다 | 프롬프트 규칙: 쓴 말 그대로 제목, 쪼개기 금지(요청할 때만), 모르는 칸은 '?' |
| 자기 전에 적고 아침 브리핑 | 01:30 밤 정리 → 아침 브리핑 카드(먼저 할 것 / 미룰 것) |
| 캘린더 4종이 다 다름 | 전부 ICS 주소로 읽는다 (아래 '오늘 확인한 것') |
| 시간표는 사진으로 | Claude가 사진을 바로 읽는다. 앱에 OCR을 넣지 않아 가볍다 |
| when2meet 직접 구현 | 친구 · 그룹 · 다 같이 빈 시간 제안 (3단계) |
| 카톡 직접 접근 X, 내보내기 O | 대화 내보내기 파일 → 일정 후보 팝업 (3단계) |
| 튜터는 미룸, 벼락치기는 좋음 | 4단계, 여유 있을 때만 |

## 오늘 확인한 것 (11-09)

- **eTL은 토큰 없이 받는 캘린더 주소(ICS)가 있다.** 프로필의 `calendar.ics`. 시험: 토큰 없이 받아짐(3.3초), 마감 있는 과제만 들어 있다(마감 없는 과제·공지·강의자료는 없음).
  → 1단계는 이 주소 하나로 과제 마감을 받는다. 공지(시험·휴강)·강의계획서는 토큰이 필요하니 3단계.
- 그래서 **모든 캘린더를 ICS 주소로 읽는다**: 구글 '비공개 주소(iCal 형식)', 애플 '공개 캘린더' 링크, 노션 캘린더는 구글 것을 씀, 삼성은 구글 계정 동기화 → 구글 주소.
  → 구글 캘린더 권한(검증 몇 주)을 기다리지 않고 시작한다. 수집기도 하나.
- **구글 로그인은 기본 정보(이름·이메일)만** 받는다 → 앱 검증·테스트 사용자 명단·7일 만료가 모두 필요 없다.

## 스택 (하나로)

- **Cloudflare (11-09 확정)**: Workers(API + 화면 파일) · D1(DB) · R2(시간표 사진) · Cron(ICS 15분마다, 밤 정리 01:30 KST). 회의 때 만들던 로그인 작업을 그대로 잇는다. 무료로 시작, 요청당 CPU 10 ms 한도에 걸리면 Workers 유료($5/월).
- **화면**: PWA. 로그인 작업에서 쓰던 틀 그대로(없으면 Vite + React). 폰은 '홈 화면에 추가'.
- **AI**: Claude API. 즉시 팝업 = Haiku 5.5, 밤 정리·브리핑·시간표 사진 = Sonnet 5.5. 호출은 `api/llm.js` 한 곳에. 콘솔에서 월 지출 상한 먼저.
- **공모전 규정**: ChatGPT Edu 사용이 조건이면 3단계에 'ChatGPT Edu에서 NGS 부르기(MCP 연결)'를 넣는다. 개발에 쓴 도구는 신청서에 사실대로 적는다.
- **저장소**: [archi142857/snu_second_brain_project](https://github.com/archi142857/snu_second_brain_project) (비공개, 제출 때 공개). 앞 출품작(졸업요건·시간표 GPT) 위에 올린다. main에 올리면 자동 배포.

## DB 표 (schema.sql 초안)

- `users`: id, email, dept, year, ics_urls, etl_token(3단계, 암호화 저장 — 비밀번호는 절대 받지 않음)
- `events`: id, user_id, title, start, end, place, source(etl·ics·memo·timetable·kakao), ext_id, important
- `tasks`: id, user_id, title, due, minutes, ready(지금 가능 / 자료 뒤), done, source, ext_id
- `memos`: id, user_id, text, created_at, handled
- `briefings`: user_id, date, text
- `log`: user_id, action, at — 측정용
- 3단계: `friends`, `groups`, `group_members`
- (user_id, source, ext_id)는 유일 → 같은 ICS를 다시 받아도 중복이 안 생긴다.

5. **배포**: main에 올리면 바로 나간다. 망가지면 Cloudflare에서 이전 배포로 되돌린다.
6. **밤샘**: '밤샘' 라벨을 단 이슈는 밤에 AI 에이전트(Claude Code 등)에 맡기고 아침에 확인한다.
7. **측정**(공모전 수치 겸, `log` 표 하나): 하루 쓴 사람 수 · 팝업을 고치지 않고 저장한 비율(AI 정확도) · 할 일 3개 완료율 · 브리핑을 연 비율 · 처리한 의견 수.
