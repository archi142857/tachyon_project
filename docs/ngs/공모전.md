# 공모전 규정 확인 (11-09)

서울대 정보화본부 'ChatGPT Edu 활용 상시 공모전'에서 확인한 것, 그래서 계획에 넣은 것, 아직 모르는 것. 계획 0단계 '공모전 규정 확인'의 결과다.

## 확인한 것

- **매달 열린다.** 참가 신청은 'SNU 비교과' 시스템(마이스누 → 비교과)으로 받는다. 9월 회차 결과는 10-16에 나왔다([정보화본부 게시판](https://ist.snu.ac.kr/category/board-186-GN-t5NOy3I3-20260521102037/), [수상작 목록](https://aiplugin.snu.ac.kr/chatgpteducontest/)). 우리는 11월 회차에 낸다. 마감 11-30(월) 23:59는 앞 출품작 때 적어 둔 날짜다.
- **포스터**: 서울대 구성원이 AI를 쓴 경험을 나누는 공모전이고, 거창하지 않아도 된다고 적혀 있다.
- **신청서 양식**(로컬 폴더의 '붙임 공모전 참가신청서'). 5매 이내를 권하고, 자세한 것은 따로 붙인다.
  1. 참가자 정보: 이름, 소속, 구분(학부생 등). 칸이 한 사람 몫뿐이다.
  2. 공모 분야(여럿 고를 수 있음): 교육·학습 / 연구 / 행정·업무 혁신 / 서비스·콘텐츠 개발 / AI 활용문화 / 자유주제.
     제출 유형: 활용 사례 / 아이디어 / 서비스·콘텐츠 / 기고·에세이 등 / 기타.
     한 줄 요약은 100자 이내.
  3. 주요 내용(칸마다 100자 안팎):
     - 가. 무엇을 해결하려 했나: ChatGPT Edu를 쓰게 된 배경
     - 나. **ChatGPT Edu를 어떻게 활용했나**: 주요 프롬프트나 결과 화면을 붙일 수 있다
     - 다. 효과: 시간 절감, 품질 향상, 편의 개선
  4. 첨부(선택): 주요 프롬프트, 결과 화면, 쓰기 전후 비교, 발표자료, 이미지·영상, 서비스 링크. 개인정보·민감정보·비공개 정보는 넣지 않는다.
- **상**(9월 회차 기준): 대상 100만 원 · 최우수 30만 원 · 우수 10만 원 · 장려 5만 원 상당 · 활용상 1만 원 상당.
- **9월 수상작에서 보이는 것**
  - 거의 모든 작품이 'ChatGPT Edu로' 또는 'ChatGPT Edu 계정으로 쓴 Codex로' 무엇을 했는지 쓴다.
  - 대상과 최우수는 실제로 돌아가는 서비스나 에이전트다.
  - 우수상 중에는 'Codex로 구현·검증한 서비스'와 'Codex로 배포 전에 웹 취약점과 설정 누락을 점검한 과정'이 있다.
- **비슷한 수상작이 이미 있다.**
  - 대상: eTL 공지·과제·첨부에 흩어진 일정을 근거와 함께 정리해, 캘린더에 없던 마감과 충돌을 알려 주는 학생용 학기 비서.
  - 장려상: eTL 캘린더에 안 뜨는 일정을 모아 주는 플래너, 대학생활 비서, 시간표와 캠퍼스 정보를 잇는 안내, 학교 메일 정리, AI 일기 등.
- **새 GPT는 이제 못 만든다(예정대로라면).** OpenAI 안내에는 새 GPT 만들기가 2026-09-25에 끝나고 기존 GPT는 12-11에 멈춘다고 되어 있다. GPT는 '플러그인'으로 옮겨진다. GPT의 '액션'은 따라 옮겨지지 않아서 커넥터나 직접 만든 MCP 서버로 다시 만들어야 한다. 엔터프라이즈 기준 일정이고, 다른 요금제도 같은 일정을 따를 수 있다고 한다.
  → 'ChatGPT Edu에서 Tachyon 부르기'를 하려면 GPT가 아니라 MCP 서버로 해야 한다. 학교 워크스페이스에서 직접 만든 MCP를 붙일 수 있는지는 아직 모른다.
- 헷갈리지 말 것: '제2회 서울대 생성형 AI 경진대회'(contest.snu.ac.kr)는 다른 대회다. 개발 도구에 제한이 없지만 접수는 9월에 끝났다.

## 판단: ChatGPT Edu를 실제로 써야 한다

'다른 AI를 쓰면 안 된다'는 규칙 문장은 찾지 못했다. 하지만 신청서 '나' 칸이 ChatGPT Edu를 어떻게 썼는지 묻고, 수상작도 모두 그것으로 설명한다. 지금 계획대로 앱 AI와 개발을 모두 Claude로 하면 '나' 칸에 쓸 내용이 없다. 그래서 아래처럼 바꾼다.

1. **개발 일부를 지금부터 Codex(ChatGPT Edu 계정)로 한다.** 가장 확실하고 비용이 안 든다. 맡길 몫:
   - (가) 공개 전 보안 점검: 비밀값, eTL·캘린더 주소, 개인 데이터가 저장소·로그·이슈에 없는지, 로그인 없이 열리는 API가 없는지. 9월 우수상과 같은 쓰임이다.
   - (나) Claude가 만든 코드를 따로 검토하고 테스트를 쓰는 일.
   - (다) 독립적인 기능 하나(예: 의견 버튼 → GitHub 이슈).
   - 프롬프트는 `prompts/`에 남기고 도구 칸에 'Codex (ChatGPT Edu)'라고 적는다.
2. **(3단계, 되면) Tachyon MCP 서버**: ChatGPT Edu에서 '오늘 뭐 해야 해?'라고 물으면 아침 브리핑을 읽어 주고, '이거 메모해 줘'라고 하면 메모를 넣는다. 11/16 회의 전에, 학교 ChatGPT Edu에 직접 만든 커넥터(MCP)를 붙일 수 있는지만 먼저 확인한다. 안 되면 접는다.
3. **앱 안 AI는 Claude 그대로 둔다.** 지금 바꾸면 일정이 무너진다. 신청서에는 사실대로 적는다: 앱 안 AI는 Claude, 개발과 검토는 Claude Code와 Codex(ChatGPT Edu).

## 신청서에서 앞에 둘 것

'eTL 일정 모으기'는 9월 대상이 이미 했다. 우리는 그다음을 앞에 둔다.

- **하루 루프**: 생각나는 대로 적은 메모가 바로 일정이 된다(즉시 확인 창). 나머지는 밤에 정리되어 아침에 '할 일 3개'가 된다.
- **한 달력과 밀도**: eTL만이 아니라 구글·애플 캘린더와 시간표 사진까지 한 달력에 모은다. 그중 여유가 적은 일부터 고른다.
- **실제로 쓴 기록**: 팀이 11/13부터 매일 쓰면서 고친 기록과 숫자. 쓴 날 수, 확인 창을 고치지 않고 저장한 비율, 할 일 완료율, 처리한 의견 수.
- **근거 표시**: 9월 대상처럼 일정이 어디서 왔는지 보여 주는 일은 우리도 싸게 할 수 있다. 할 일과 일정마다 출처(eTL, 구글, 메모 원문)를 한 줄 붙인다.

## 제출 때 (계획 5단계에 넣음)

- 공모 분야는 서비스·콘텐츠 개발(+ 교육·학습), 제출 유형은 서비스·콘텐츠.
- 신청서는 5매 이내. 가·나·다 칸이 100자 안팎이라 숫자를 위주로 쓴다.
- 첨부: 서비스 링크, 시연 영상, 프롬프트 원문(`prompts/`), 쓰기 전후 비교. 실제 일정·이름·학번·이메일·캘린더 주소가 보이는 화면은 빼거나 가린다.
