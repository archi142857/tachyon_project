### 결정과 개선

- **대학원 일요일 수업:** 원본에 대학원 일요일 수업이 있어 첫 검증이 중단됐다. 대학원은 구조만 확인하고 제외하며, 출력 대상인 학사의 요일·시각 검증을 유지했다.
- **빠진 지점:** 기본 세 좌표 파일에 없던 71-1동과 정문은 TT Wizard가 사용하는 `buildings_for_magicmap.csv`에서 보완했다. 좌표를 추정하지 않았다. 이 보완 파일의 비고와 연도 열은 버린다.
- **교수 정보 검사:** 실제 인명과 일반 명사가 같은 글자일 수 있어 문자열 전체 차단은 공식 과목명을 잘못 막았다. 교수 열·메타가 출력으로 복사되지 않았는지를 허용 필드 대조로 검사하고, 합성 고유 표식이 파일·로그·오류에 남지 않는지도 확인한다. 공식 과목명은 바꾸지 않는다.
- **일관된 갱신:** 더 이상 수집하지 않는 정규학기 생성 파일은 정리하되 졸업요건·설명문·비관리 파일은 보존한다. 검증 실패 시 기존 자료를 유지하고, 파일 교체 중 오류가 나면 복원한다.
- **개설 빈도:** 2026년 기준 최근 5년은 2022~2026년이다. 같은 과목의 여러 분반은 한 해의 개설 한 번으로 센다. 공개된 미래 편람은 최근 5년 빈도에는 더하지 않고 마지막 개설 정보에만 반영한다. 폐강대상 표시도 원본대로 보존한다.
- **재현 확인:** 원본 파일 해시, 기준연도, 학기·과목·분반 수를 기록하고 실행 시각은 넣지 않아 같은 입력이 같은 파일을 만든다.
