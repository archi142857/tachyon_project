# 자료 이용·학교 연동 문의 초안

작성일: 2026-11-07 · 담당: Project / Legal · **모두 미발송**

[검토 현황](검토_현황.md)의 L01~L11을 확인하기 위한 문안이다. 실제 학생 정보·계정·성적표·비공개 회신은 첨부하지 않는다. 아래 수신 대상은 담당 업무이며 특정 수신 주소를 추정하지 않았다. 발송 여부·방법은 이번 작업에서 정하지 않는다.

## Q01. 이동시간 데이터의 GPT 제공 범위

수신 대상: 캠퍼스 마법 지도 자료 권리자, 필요시 학교 Edu 계약 담당. 관련: L02·L06.

제목: ODbL 이동시간 표의 GPT 지식파일 제공 조건 확인

안녕하세요. TT Wizard의 분 단위 이동시간 표를 활용하는 학생 비공식 학업계획 도구를 준비하고 있습니다. 원본 저장소의 2026년 11월 7일 고지는 다른 이용자에게 ODbL 1.0을 적용한다고 명시하고 있어, 출처·라이선스와 파생 데이터 제공 조건을 유지하는 방안을 검토 중입니다.

별도 확인하고 싶은 범위는 ChatGPT Edu의 지식파일로 제공하고 구성원과 GPT를 공유하는 경우입니다. OpenAI Service Terms 제5조 (b)는 GPT 공유 시 콘텐츠에 대한 이용 권한을 OpenAI와 출력 수령자에게 부여하도록 규정합니다.

이 제공 방식에서 원자료에 관해 추가로 확인해야 할 권리나 조건이 있는지 안내 부탁드립니다. 기존 무료 배포 허락이 이번 GPT 제공 방식까지 다뤘는지, 필요한 출처·라이선스·공개 사본 안내 방식이 있는지도 확인하고 싶습니다. 일반 ODbL 이용 전체에 추가 허가가 필요하다고 전제하는 문의는 아닙니다.

## Q02. 공개 편람·캠퍼스맵·계획서와 개인 학사 연동

수신 대상: 정보화본부, 수강편람/학사정보 운영 부서, 캠퍼스맵 자료 담당. 관련: L01·L03·L08·L09. Integrations Q1~Q5와 대응.

제목: 비공식 학업계획 시제품의 공개 자료 이용과 공식 연계 경로 문의

안녕하세요. 학생의 이수 과목을 공개 졸업요건과 대조하고 시간표·이동시간을 안내하는 비공식 시제품을 개발 중입니다. 이번 개발·검증에는 가상 학생 자료와 모의 응답을 사용합니다. 실제 학교 계정 자동 조회나 정기 수집은 수행하지 않고 있습니다.

다음 항목을 담당 부서별로 안내받고 싶습니다.

1. 공개 강좌·분반·강의실·학점·개설 이력 및 캠퍼스 건물 번호·이름·좌표의 추출, 저장, GitHub 재배포, GPT 지식파일 제공에 적용되는 조건은 무엇인가요? 교수 이름은 제외할 계획입니다.
2. 본인 이수내역과 확정 전공을 읽는 공식 API·내보내기·위임 인증 방식이 있나요? 지원된다면 허용 항목·승인 절차·테스트 환경·인증 만료/해제·호출 제한을 알고 싶습니다. 전공 신청/선발 내역과 확정 전공을 구분하고자 합니다.
3. 전체 학기·전체 페이지 조회 완료, 취득 완료/수강 중, 재수강·교과구분을 확인할 공식 필드는 무엇인가요?
4. 강의계획서의 게시/미게시 여부, 한글·영문·분반 차이, 수정·업로드 시각, 원문 링크를 공식적으로 확인하는 방법이 있나요? 빈 화면이나 오류는 미게시로 판단하지 않을 예정입니다.
5. 계획서 게시 상태의 반복 조회·캐시·알림용 상태 기록·원문 링크 안내·본문 복제 각각 허용 범위와 조회 빈도는 무엇인가요?

강의계획서 ‘등록’은 계획서 게시를 뜻하며 수강신청·취소를 제출하는 기능은 이번 범위에 없습니다. 공개 경로 안내가 외부 자동 조회 허가를 의미한다고 보지 않고 확인을 요청드립니다.

## Q03. 학생 입력 처리와 학교 Edu 사용 범위

수신 대상: 정보화기획과(ChatGPT Edu), 총무과·정보화지원과(개인정보 담당). 관련: L06·L07·L10·L11.

제목: 학생 비공식 GPT의 최소 이수정보 입력·보존 및 Edu 가용성 확인

안녕하세요. 가상 학생 자료로 검증 중인 비공식 학업계획 도구의 실제 운영 조건을 검토하고 있습니다. 학교 개인정보처리방침의 ChatGPT Edu 항목에는 성명·이메일주소·신분·서비스 이용기록이 기재돼 있음을 확인했습니다.

학생이 본인 과목번호·과목명·학점·이수 상태·적용 학번 연도·전공을 입력하는 경우 다음을 확인하고 싶습니다. 이름·전체 학번·생년월일·점수는 계산에 사용하지 않고 공개 저장소에도 넣지 않습니다. 이 제거만으로 완전한 익명정보라고 보지는 않습니다.

1. 학교·개발자·OpenAI 각각의 처리 역할과 적용되는 계약·내부 이용 지침은 무엇인가요? 기존 방침 항목 외의 이수정보 처리에 필요한 근거·고지·동의가 있나요?
2. 대화·첨부파일·별도 저장 파일·중간 계산·로그의 보유 기간, 관리자 접근, 삭제 요청·백업 처리, 국외 처리 국가/수령자·기간·거부 방법은 어떻게 안내해야 하나요?
3. 지식파일에는 개인 자료를 넣지 않고 공통 규정·계산 자료만 제공하려 합니다. 제3자 DB를 포함한 GPT 공유에 학교 계약상 추가 조건이 있나요?
4. 학교 Edu에서 현재 GPT 신규 생성과 구성원 공유가 가능한가요? OpenAI 공식 GPT 종료·이전 안내가 학교 워크스페이스에 적용되는 일정과 공모전에서 사용할 수 있는 제출 형태를 알려 주실 수 있나요?

판정은 학생의 참고용으로 제시하고 졸업 사정은 학과·마이스누에서 최종 확인하도록 안내할 계획입니다. 실제 자동 조회에 대한 승인·기술 경로는 이 개인정보 문의와 별도로 확인하겠습니다.

## Q04. 분 단위 시간표의 공간정보 규정 적용

수신 대상: 국토교통부/국토지리정보원 지도 간행·측량성과 국외반출 담당. 관련: L04.

제목: 수치지형도 기반 분 단위 이동시간 산출물의 간행·국외 제공 범위 문의

안녕하세요. 수치지형도에서 얻은 경사 정보를 계산 과정에 반영한 지점 간 이동시간 표의 이용 조건을 확인하고 싶습니다. 선행 프로젝트 기록상 입력은 수치지형도 V2.0의 1:5,000·1:1,000이며, 제공을 검토하는 출력은 출발 지점·도착 지점·분 단위 시간입니다. 원본 지도, 고도·등고선·경사 표와 3D 지형은 제공하지 않습니다.

이 시간 표를 공개 GitHub 또는 ChatGPT Edu 지식파일로 제공할 경우 공간정보의 구축 및 관리 등에 관한 법률 제15조의 간행심사나 제16조의 국외 반출 허가 대상인지 확인 부탁드립니다. 저작권상의 공공누리 표시와 별도로 검토하고자 합니다. 판단에 필요한 생성 과정·자료 품목·출력 명세와 담당 부서를 안내해 주세요.

## Q05. 졸업요건 원문 재배포가 필요한 경우에만

수신 대상: 해당 문서 게시 학과·단과대학/작성 부서. 관련: L05. **공개 사실 조사·구조화를 시작하기 위한 선행 문의가 아니다.**

제목: 졸업요건 안내 자료의 원문·도표 재사용 조건 확인

안녕하세요. 공개된 졸업요건에서 학점·과목번호·적용 학번 등 사실을 출처와 함께 직접 정리하는 학생 비공식 도구를 개발 중입니다. 이와 별도로 원문 PDF·설명문·도표를 그대로 저장하거나 GPT 지식파일로 제공할 필요가 생길 경우, 재사용 가능한 범위와 출처 표시·수정·재배포 조건을 확인하고 싶습니다. 제3자 저작물이 포함돼 있다면 해당 범위도 안내 부탁드립니다.

실제 문의 시 해당 문서명·공식 URL·판본·필요한 페이지·제공 범위를 구체화합니다. 공개 사실 구조화와 원문 재배포를 같은 허가 문제로 취급하지 않습니다.

## 회신을 받을 경우 남길 기록

- 질문 ID, 확인한 부서·회신일, 대상 파일/자료·이용 방식·범위·기간·표시 조건.
- 근거 문서 또는 개인정보 없는 회신 요약. 발신자 서명·연락처·내부 정보가 포함된 원본은 공개하지 않는다.
- 허용/불가/추가 조건/답변 없음의 구분. 답변이 없는 항목은 허용이나 금지로 바꾸지 않는다.
- 기술 조회 검증은 Integrations, 제품 범위 결정은 Concept에 전달한다.
