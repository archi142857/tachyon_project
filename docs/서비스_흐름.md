# 어떤 정보를 받아 어떤 시간표를 제안하나요?

**개인의 이수내역·학과·복수전공·졸업요건을 함께 살펴보고, 수업 겹침과 강의실 이동시간을 계산해 다음 학기 시간표 3안을 제안합니다.**

이 문서는 완성할 서비스의 흐름입니다. 현재는 강좌·걷는 시간·건물·개설 이력 자료를 준비한 단계이며, 아래 졸업요건 대조와 시간표 추천 기능은 작업 2~4에서 구현합니다.

강의계획서 모아보기와 등록 알림도 추가 요구사항으로 정리했습니다. 이 기능은 공식 조회 경로와 알림 방식 확인이 필요한 설계 단계입니다.

**가능한 과정은 자동으로 이어지게 합니다.** 확장 목표는 학교 로그인 → 이수내역·전공 정보 불러오기 → 요약 한 번 확인 → 졸업요건 대조와 시간표 3안 계산 → 선택한 과목의 계획서 모아보기·등록 알림입니다. 이미 읽은 정보를 다시 묻거나 학생이 단계마다 실행 버튼을 누르게 하지 않습니다. 실제 학교 연동은 확인 필요이며, 자세한 경계와 검증 기준은 [자동화 흐름](자동화_흐름.md)에 적었습니다.

## 1. 학생의 상황을 확인합니다

- **이수내역:** 이미 들은 과목, 과목번호, 취득 학점, 교양·전공 등의 이수 구분.
- **적용할 전공 정보:** 입학연도, 소속 학과, 주전공, 복수전공 여부와 전공명.
- **선택 사항:** 다음 학기에 원하는 학점, 피하고 싶은 요일·시간, 주로 출발하는 곳.

학교 연동이 가능한 단계에서는 학생이 공식 로그인 화면에서 직접 로그인하면 이수내역과 제공되는 전공 정보를 자동으로 불러옵니다. 내부 브라우저에서 로그인할 수 있는지는 학교 연결 방식 확인 후 결정합니다. 로그인 성공만으로 자료를 모두 읽었다고 처리하지 않고, 조회 범위·학기·과목 수를 확인합니다. 수강 중인 과목은 취득 완료 과목과 구분합니다.

첫 시범과 연결이 어려울 때는 이름·학번·생년월일을 지운 성적표 PDF나 과목 표를 제공합니다. 전체 학번 대신 입학연도만 사용하고, 성적 점수나 이름은 계산에 쓰지 않습니다. 어느 경로든 읽은 과목과 전공 정보를 한 번에 보여 주고 확인받습니다. 자료에 없는 필수 정보만 한 번에 묻고, 수강 과목만 보고 학과나 복수전공을 추측하지 않습니다. 선택 사항은 답이 없으면 기존 지침의 기본값을 사용합니다.

졸업요건의 첫 시범 범위는 2025학번 동물생명공학전공·생명과학부·화학생물공학부의 주전공과 복수전공입니다. 자료가 없는 전공이나 학번의 요건은 임의로 적용하지 않습니다.

## 2. 남은 졸업요건을 찾습니다

이수내역을 해당 학번과 전공의 공식 졸업요건에 대조합니다. 주전공과 복수전공의 필수과목·최소 학점, 교양 영역과 지정 과목을 함께 확인합니다.

각 항목에는 채운 부분과 남은 부분, 근거 문서·조항·링크를 붙입니다. 같은 과목을 두 요건에 함께 셀 수 있는지 불명확하면 ‘확인 필요’로 남깁니다. 논문·시험처럼 수업 선택만으로 해결되지 않는 조건도 별도로 보여 줍니다.

## 3. 다음 학기에 들을 과목을 고릅니다

남은 필수과목, 권장 이수 학년·학기, 먼저 들어야 하는 과목의 이수 여부, 개설 이력을 살펴 후보를 정합니다. 이미 이수한 과목과 전공 간 인정 관계도 함께 확인합니다. 각 후보에 ‘어느 졸업요건을 채우기 위해 추천했는지’를 표시합니다.

다음 학기 수강편람이 없으면 지난 같은 학기의 분반을 사용하고 **‘예상 시간표’**라고 표시합니다. 과거에 열렸다는 사실을 다음 학기 개설 확정으로 표현하지 않습니다.

## 4. 수업 시간과 동선을 계산합니다

| 확인할 것 | 처리 방법 |
| --- | --- |
| 수업 시간 겹침 | 시간이 겹치는 조합은 제외합니다. |
| 수업 사이 걷는 시간 | 앞 수업의 강의실에서 다음 강의실까지 방향별 걷는 시간을 계산합니다. |
| 이동 여유 | 수업 사이 빈 시간에서 걷는 시간을 뺍니다. 부족한 구간은 ‘빠듯함’으로 표시합니다. |
| 한 주의 이동 부담 | 주간 걷는 시간과 빠듯한 구간의 부족 시간을 함께 비교합니다. |
| 강의실 미정 | 해당 이동은 계산에서 제외하고 ‘확인 필요’로 표시합니다. 실제 이동이 0분이라고 설명하지 않습니다. |
| 학생의 선택 조건 | 목표 학점, 피하고 싶은 요일·시간, 출발 지점을 함께 반영합니다. |

시간표를 비교하는 계산은 기존 TT Wizard의 기준을 그대로 사용합니다. 주간 걷는 시간에 이동 여유가 부족한 시간의 두 배를 더한 값이 작을수록 앞에 둡니다. 이동이 빠듯한 조합은 부담을 더 크게 반영하고 결과에 표시합니다.

## 5. 학생이 비교할 수 있는 3안을 보여 줍니다

각 안에 다음 내용을 함께 제공합니다.

- 요일별 시간표, 선택한 과목·분반, 총 학점.
- 각 과목의 추천 이유와 채우는 졸업요건.
- 수업 겹침 검사 결과.
- 수업 사이 걷는 시간·남는 여유·빠듯한 구간.
- 한 주 걷는 시간 합계와 TT Wizard 동선 지도를 여는 링크.
- ‘예상’ 여부, 추가로 확인할 사항, 자료 출처.

조건에 맞는 서로 다른 조합이 3개보다 적으면 가능한 안만 보여 주고 부족한 이유를 설명합니다. 확인할 수 없는 조건을 충족했다고 단정하거나, 학생이 피하겠다고 한 시간을 말없이 바꾸지 않습니다.

## 6. 관심 과목의 강의계획서를 모아 보고 등록 알림을 받습니다

학생이 시간표를 선택하면 그 시간표의 과목으로 강의계획서 목록을 자동 구성합니다. 비교할 다른 과목도 추가할 수 있습니다. ‘이 시간표의 계획서 알림 받기’를 한 번 켜면 대상 과목을 한꺼번에 등록하고 정기 확인을 이어갑니다. 과목명만으로 묶지 않고 **학기·교과목번호·강좌번호**를 함께 사용해 다른 분반의 계획서가 섞이지 않게 합니다. 학생이 알림을 켠 과목만 정기 확인 대상으로 삼습니다.

한 목록에서 계획서 등록 상태, 마지막 확인 시각, 공식 원문을 보는 경로를 확인합니다. 처음에 없던 계획서가 나중에 등록되면 한 번 알립니다. 관심 목록에 담고 첫 조회에서 이미 있던 계획서는 ‘등록 확인’으로 표시하고, 방금 업로드됐다고 표현하지 않습니다. 접속 오류나 로그인 필요로 조회하지 못한 경우도 ‘미등록’과 구분합니다.

이 기능은 학생이 수업 내용을 살펴 최종 시간표를 고르는 것을 돕습니다. 계획서 미등록만으로 시간표 후보에서 과목을 제외하지 않습니다. 조회 방식·확인 주기·알림 수단과 검증 기준은 [강의계획서 모아보기와 알림](강의계획서_모아보기와_알림.md)에 정리했습니다.

## 공모전에서 보여 줄 것

지어낸 학생의 이수내역과 전공 정보를 넣었을 때, **왜 그 과목을 골랐고 왜 그 시간표가 나왔는지** 따라갈 수 있게 시연합니다. 수작업으로 확인한 졸업요건, 시간 겹침, 이동시간과 계산 결과를 대조합니다. 처리시간과 정확도는 실제로 측정한 뒤 공개합니다.

강의계획서 알림을 시연할 때는 지어낸 등록 상태로 ‘미등록 확인 → 등록 확인 → 알림 한 번’을 재현합니다. 이런 시연은 **모의 시연**으로 표시하고, 실제 학교 자료를 주기적으로 조회해 알림을 보낸 결과와 구분합니다.

학생이 만든 비공식 도구예요. 졸업 사정은 학과와 마이스누에서 최종 확인하세요. 다른 사람의 성적표는 올리지 마세요.
