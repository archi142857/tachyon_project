# 자율 진행 작업 배정

2026-11-07 · Concept 관리. 사용자가 같은 프로젝트 세션 간 직접 요청·보고와 자율 진행을 지시했습니다. 이 표는 배정할 범위이며, 실제 전달·착수·완료는 각 세션 인수인계와 실행 결과로 확인합니다.

기준 커밋: `758192a`. 시작 기준은 자료 생성, 졸업요건 자료 준비·검증(2-A), 이수내역 정리(2-B) 완료입니다. 기준 전체 테스트 148개 통과. 2-C·시간표·실제 GPT·학교 연결은 아직 완료가 아닙니다.

## 첫 결과 통합 시점의 갱신

2026-11-07 후속 확인: 아래 표의 첫 작업은 Research 해석·제안, Planner 2-C, Integrations 모의 상태·알림, Frontend 로컬 가상 통합 검증, Legal 근거 검토까지 담당 완료 보고를 받았습니다. 전체 테스트 250개가 통과했고 Document가 최종 현황·기록을 통합합니다. 시연 기록은 Planner 최종 코드와 일치하는지 다시 확인합니다. 이는 시간표·실제 GPT·학교 연결 완료가 아닙니다.

통합 커밋·푸시를 위해 이번 포함 파일은 담당 마감 후 쓰기를 잠시 멈춥니다. 다음 최우선 작업은 **Planner 작업 3: 과목 후보·시간표·동선 계산**입니다. 입력은 고정 1.0 요건 대조 결과·개설 자료·방향별 이동시간·학생 조건이며, 시간 겹침 금지, 이동 부족·미정 강의실 표시, 미래 편람이 없을 때 예상 표시, 실제 가능한 최대 3안과 부족 이유를 독립 검증합니다. 첫 통합 완료 후 Concept이 실행 요청으로 연결합니다.

Concept은 완료 보고와 파일·검증을 대조하고, 2-C 결과가 통과하면 Planner의 작업 3(과목 후보·시간표·동선)으로 연결합니다. 기능 개발과 무관한 문서 정리를 필수 대기 단계로 만들지 않습니다. 결과가 없어도 진행 가능한 독립 작업은 계속합니다.

2026-11-07 Legal 중간 보고의 [OpenAI GPT 종료·이전 안내](https://help.openai.com/en/articles/20001519-custom-gpt-retirement-and-migration-faq)를 Concept도 확인했습니다. 일반 종료 예정일은 2026-12-11이며 서울대 Edu의 실제 일정·생성·공유 권한은 계정 안내 확인이 필요합니다. 계산·가상 시연·재사용 가능한 지침 개발은 계속하고, 실제 GPT 생성·공유·전환 완료는 확인 전까지 주장하지 않습니다. Legal이 근거와 제품 영향을 Frontend·Document에 전달하도록 배정했습니다. 이 안내 자체를 전체 개발의 대기 조건으로 삼지 않습니다.

## 실행과 전달 규칙

- 실제 작업은 [세션 운영](세션_운영.md)의 담당 파일과 공통 지침을 따릅니다. 다른 세션에 요청할 때 입력·산출물·완료 기준·수정 범위를 명시합니다.
- 같은 사용자 작업의 지시를 확인하고 이 범위의 직접 요청·결과 전달을 진행합니다. 새 세션을 임의로 만들거나 관련 없는 대화에 전달하지 않습니다.
- 각 세션은 결과와 다음 담당을 자기 인수인계에 기록합니다. 실제 전송이 안 됐으면 전달 완료로 표시하지 않습니다. 반복 확인·서로 재전송하는 보고 순환을 만들지 않습니다.
- 후속 사용자 요청에 따라 Concept이 완료·검증된 변경을 모아 커밋·푸시합니다. 다른 세션은 직접 커밋하지 않으며 통합 시 포함 파일과 검증 근거를 보고합니다. 실제 학교 연동·자료 재배포·서비스 공개·외부 발송은 남은 기존 조건을 따릅니다.
- 사용자 직접 지시와 AI 세션 간 지시·보고를 분류해 모든 작업 요청·처리 결과를 기록합니다. 공개용 기록에서 내부 식별자 등은 가림 사실을 표시합니다.
