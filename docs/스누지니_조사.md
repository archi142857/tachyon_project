# 스누지니 조사: 서비스 범위와 개편, 현재 확인 가능한 상태

**조사일: 2026-11-06, 한국 시간 기준.** 공개된 학교 자료와 제작사의 직접 발표를 조사했습니다. 기존 기능과 2026년 개편 발표를 합쳐 비교 기준을 만들었으며, 로그인해서 모든 기능을 실행한 결과는 아닙니다. 구현 목표와 완료 기준은 [스누지니 구현목표](스누지니_구현목표.md)에 연결합니다.

## 먼저 확인한 사실

- 정보화본부의 공개 안내는 **2026-10-27 10:00부터 별도 안내까지 보안 점검에 따른 전체 서비스 일시 중단**을 알립니다. 재개일은 공지에서 제시하지 않습니다. 영구 종료나 특정 침해사고 발생으로 해석할 근거는 없습니다. 대체 경로로 마이스누 졸업시뮬레이션과 수강신청시스템을 안내합니다. [S01][s01]
- 기존 서비스에는 교과·전공·비교과 탐색뿐 아니라 학업이수현황과 학습케어도 있었습니다. 학교 공식 서비스 대상에는 재학생 외에 교수·직원도 포함됩니다. [S02][s02]
- 2026년 고도화에는 AI 대화와 개인화, 학년·학기별 계획 기능이 이미 발표됐습니다. 따라서 ‘대화로 추천한다’거나 ‘학업 로드맵을 만든다’는 것만으로 우리 서비스의 우위를 주장할 수 없습니다. 이는 구축업체의 완료 발표이며 이번 조사에서 실제 동작을 독립 검증하지 않았습니다. [S10][s10]

## 우리 목표에 주는 의미

아래는 조사 결과를 토대로 한 **우리 설계 판단**입니다. 스누지니의 성능을 측정한 결론이 아닙니다.

- 기능 목록은 최소 비교 범위로 유지합니다. 초기 2025학번 3개 전공 시범을 끝내도 학교 전체 기능을 모두 대체했다고 표현하지 않습니다.
- 한 과목을 추천하는 이유를 졸업요건·관심 분야와 연결하고, 실제 분반 조합의 충돌과 이동 여유까지 계산해 실행 가능한 선택지를 만드는 것을 우선합니다.
- 전공·다전공 인정, 선수·대체 과목, 개설 불확실성, 선택을 바꿨을 때의 영향을 같은 계산에 연결합니다.
- 개인 수강이력과 전체 개설이력은 다른 자료입니다. 우리 저장소의 개설 기록을 ‘선배들이 실제로 들은 경로’나 ‘학년별 수강 통계’로 바꿔 부르지 않습니다.
- 교수자 탐색, 성적을 쓰는 학습케어, 학교에 제출하는 신청·승인 처리는 현재 지침·접근 범위와 차이가 있습니다. 기능표에서 빼거나 약한 대체 기능을 동등하다고 세지 않고, 구현목표에 미충족 범위로 남깁니다.
