## 2. Tachyon이 더 잘할 수 있는 것: 들은 과목을 eTL에서

TT Wizard는 학기마다 시간표를 저장해 둔 사람만 '들은 과목'이 채워진다. Tachyon은 eTL 토큰 연결(`9_etl.js`)이 이미 과목마다 교과목번호(`sbjtCd`)와 분반(`ltNo`)을 강의계획서 칸에서 읽는다 — 지금은 이번 학기(`enrollment_state: active`)만.
지난 학기까지 받으면(`enrollment_state: completed`, 확인 필요) 학기 · 교과목번호 → 편람(`data/offerings/<학기>.json`: 학점 · 이수구분 · 개설 학과)으로 **들은 과목을 저절로** 채울 수 있다. 사람은 TT Wizard처럼 드랍 · F만 고친다.

## 4. 모아야 하는 정보(B를 한다면)

- **사람에게서(화면에서 고름):** 학번(입학 연도 — 지금 Tachyon은 첫 설정 때 학년만 저장해서 다시 확인), 주전공 과정, 복수전공 · 부전공(있으면, 선발 학기), 드랍 · F 과목 표시. 성적(평점)은 받지 않는다.
- **eTL에서(토큰이 있는 사람만):** 지난 학기 과목의 학기 · 교과목번호 · 분반. 서버에 따로 저장하지 않고 그때그때 받아 화면이 계산(TT Wizard처럼 기기 안에서).
- **TT Wizard Pages에서:** `index.json` · `catalog.json` · `common.json` · `ge_credits.json` · `course_map.json` · `same_courses.json` · `ge_areas.json` · `lecture_lang.json`(합 약 0.8 MB) + 고른 과정 파일(`programs/<id>.json`, 하나 50 KB 안팎).
- **팀이 정할 것:** 처리방침 초안에 '지난 학기 과목 목록(eTL)을 졸업 요건 계산에만, 저장 안 함' 한 줄. TT Wizard 법무 메모(`요청_법무.md`)의 '성적 저장 안 함'을 그대로 따른다.
