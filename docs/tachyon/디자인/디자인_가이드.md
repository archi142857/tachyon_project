## ③ 규칙

- 흰 바탕에 가는 선. 카드는 옅은 선(`--line`)으로 나누고, 먹 선(`--line-strong`)은 입력 칸·쪽 머리·무리 제목 밑줄에만.
- 색은 점(입자)과 작은 모양에만 쓴다. 색 하나에 뜻 하나:

| 색 | 뜻 | 모양 | 값 |
|---|---|---|---|
| 빨강 | 지금(실시간 표시), 시간 경고(마감 지남·지각·넘침) | 선 · 글자 · 바깥 테 | `--now` `--danger` #c4321e. 다른 테마도 '지금'은 빨강 계열(사람 11-11 23:25, tokens.css C) |
| 파랑 | 수업 | ● | `--mark-class` #1e4d9b |
| 노랑 | 할 일(넣어 본 자리·마감) | ▲ 늘 먹 테두리와 같이(노랑만으로는 흰 바탕에서 1.9:1) | `--mark-task` #edb200, 면은 `--highlight` #fcf1c9 |
| 먹 | 내 일정(가져온 달력·메모) | □ 흰 면 + 먹 테두리 | `--ev-mine-line` |
| 검정 | 버튼 · 고른 것 · 초점 | 알약 · 동그라미 | `--accent` `--focus` #141414 |

- 색만으로 가르지 않는다. 모양(● □ ▲ ―)과 글(시각·남은 시간·D-n)이 늘 같이 있다. 모양 규칙은 테마가 바뀌어도 같고, 색만 테마 값을 따른다.
- 글꼴: 본문 Pretendard, 제목·날짜·숫자는 Jost(한글은 Pretendard로 이어진다). 손글씨 없음. 가장 작은 글 12px.
- 모서리: 면(카드·칩·시트)은 0, 누르는 것은 24(48 높이에서 알약, 정사각에서 동그라미), 말풍선 20. 그림자 대신 떠 있는 것에 먹 테두리 1px.
- 누르는 영역 48. 글자 4.5:1, 선·표시 3:1.
- 폰은 한 화면에 한 가지(사람: "모바일에서 너무 많은 정보가 보여서 난잡하면 안 됨"). 쪽(오늘·달력·할 일·메모·같이) 안에서 다시 한 칸(하루|일정|할 일, 주|월). 월 보기는 폰에서 글 대신 모양만 보이고 글은 칸의 aria-label에 있다.
- 모든 기기에서 꽉 차게(사람: "여백 너무 남기지 말고"). 틀은 100dvh, 스크롤은 카드 안 목록만. 여백 눈금은 폰 12·8, 넓은 화면 16·12.

```jsx
{[...arcs].sort((x, y) => x.from - y.from).flatMap((a, i, l) => {
  const prev = l[i - 1];
  if (!prev || a.from - prev.to >= 30) return [];
  const f = a.from / 1440;
  return [<line key={`sep-${a.key}`} className="sep" x1={point(60, f)[0]} y1={point(60, f)[1]} x2={point(108, f)[0]} y2={point(108, f)[1]} />];
})}
```

   입자 테마(`ParticleRing`)는 같은 자리의 입자 하나를 빼는 것으로 같은 뜻을 내면 된다.

**오늘 저녁 실사용 전에 넣을지(디자인 생각):** ④ 고리 금은 JSX 몇 줄 + CSS 한 줄이라 넣기를 권한다. ① 겹쳐 보기는 서버 주소(3830ac1)가 있어 값 · CSS만 붙이면 되니 시간이 되면 넣는다. ② 위젯 끌기와 ③ 일정 끌기는 손가락 · 키보드 · 저장 · 되돌리기까지 커서 실사용 뒤를 권한다. ②의 배치 넷 고르기(끌기 없이)만 먼저 넣는 것도 된다.
