# 디자인 (디자인 세션이 맡음)

Tachyon 디자인 가이드를 두는 곳이다. 디자인 세션([시작 프롬프트](../세션_프롬프트/디자인.md))이 채운다.

- `배운_원칙.md` — 다른 프로젝트(휴게소 추천 앱, TT Wizard, 새바라기, Grid Game, Steam Atlas, Ultimate RSP)의 디자인 가이드·디자인 시스템·디자인 북에서 뽑은 원칙 165개, 사용자가 직접 정한 것, 서로 부딪히는 원칙, 종이 플래너 방향 점검(11-10)
- `디자인_가이드.md` — 고른 방향(11-11: ③ 바우하우스 칸딘스키 점·선·면이 앱 기본, ② 차분한 종이는 테마) 요약, ③ 규칙(색 하나에 뜻 하나), 새 틀과 새 부품 표, 화면 세션에 넘길 표, 점검, 글꼴 라이선스
- `tokens.css` — CSS 변수. A 기본(바우하우스, `styles.css` 맨 위와 바꿈) · B 차분한 종이(`themes.css` 맨 앞으로) · C 다른 테마 다섯에 더할 줄(11-11). ②의 어둡게 블록은 뺐다(테마 '입자 밤'·'호박색 터미널'이 어두운 쪽, 옛 값은 git 10db9b6)
- `components.css` — 부품 CSS. 첫째·둘째 묶음(11-10, `styles.css`와 클래스 이름이 같고 바뀐 줄에 `[바뀜]`·`[새]`), 셋째 묶음(11-11, 컨셉 22:27 요청의 새 틀·밀도 고리·월 보기·마감 글·같이 쪽)
- `참고/바우하우스_미리보기_폰.png` · `참고/바우하우스_미리보기_넓은화면_월.png` · `참고/바우하우스_미리보기_넓은화면_오늘.png` — ③을 web 사본(11-11 main)에 입혀 `?example`로 본 화면(11-11, 예시 자료). 폰은 오늘 하루·오늘 일정·달력 주·달력 월.
- `참고/종이플래너_원본_읽기.md` — 팀원 종이 플래너 원본(드라이브)을 읽고 값·부품·움직임을 글로 옮긴 것과 원칙 점검(11-10). 원본 파일은 공개 저장소에 올리지 않았다.
- `참고/팀원_종이플래너_시안.png` — dhsrua555 시안 '종이 플래너' 캡처(11-10). 사용자가 "아이디어로 가지고 갈 듯"이라고 함(확정 아님). 예시 자료는 지어낸 것.
- `참고/팀원_종이플래너_시안_폰화면.png` — 같은 시안을 폰 브라우저로 본 캡처(11-10 사용자가 보냄). 폰 홈 = 오늘 쪽 + 오른쪽 색인 탭(오늘·주간·메모·브리핑), 데스크톱 = 두 쪽 펼침.
- `참고/팀원_아이디어_보고.md` · `참고/팀원_아이디어_보고.html` — dhsrua555 쪽 아이디어 보고(11-11). 처음 구상(기획안)·11-09 회의·바깥 조사를 다시 읽고 입자 고리 시안에 되살릴 것, 처음 쓰는 사람과 쓰던 게 있는 사람을 위한 아이디어 40여 개, 먼저 할 일곱 가지, 둘이 정할 일곱 가지(추천 붙임, 확정 아님)를 적었다. 글은 `.md`, 눌러 보는 그림은 `.html`(내려받아 브라우저로). 제안이며 앱에는 아무것도 적용하지 않았다. 예시 자료는 지어낸 것.
- `참고/팀원_시연/` — dhsrua555 쪽 눌러 보는 시안 묶음(11-11). 지금 판(9판) `시연-PC.html` · `시연-모바일.html`, 옛 판(6판 · 7판 · 첫 입자 고리), 같이 둔 글 두 개. 보는 법과 판마다 다른 점은 그 폴더 [README](참고/팀원_시연/README.md). 예시 자료는 지어낸 것, 제안이며 확정 아님.
- `테마_만드는_법.md` — 앱의 테마(색·모서리·글꼴 값 묶음)와 새 테마를 넣는 두 길(앱에 글 붙여 넣기 / `web/src/themes.css`에 블록 더하기), 값 이름 목록(11-11). 화면 세션이 tokens.css를 옮기면 기본은 바우하우스, 테마는 일곱 개.
