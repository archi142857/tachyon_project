# 디자인 (디자인 세션이 맡음)

Tachyon 디자인 가이드를 두는 곳이다. 디자인 세션([시작 프롬프트](../세션_프롬프트/디자인.md))이 채운다.

- `배운_원칙.md` — 다른 프로젝트(휴게소 추천 앱, TT Wizard, 새바라기, Grid Game, Steam Atlas, Ultimate RSP)의 디자인 가이드·디자인 시스템·디자인 북에서 뽑은 원칙 165개, 사용자가 직접 정한 것, 서로 부딪히는 원칙, 종이 플래너 방향 점검(11-10)
- `디자인_가이드.md` — Tachyon 디자인 가이드 요약과 'Tachyon 디자인 시스템' 아티팩트 링크(준비 중)
- `tokens.css` — 화면 세션이 가져다 쓰는 CSS 변수(준비 중)
- `참고/팀원_종이플래너_시안.png` — dhsrua555 시안 '종이 플래너' 캡처(11-10). 사용자가 "아이디어로 가지고 갈 듯"이라고 함(확정 아님). 예시 자료는 지어낸 것.
- `참고/팀원_종이플래너_시안_폰화면.png` — 같은 시안을 폰 브라우저로 본 캡처(11-10 사용자가 보냄). 폰 홈 = 오늘 쪽 + 오른쪽 색인 탭(오늘·주간·메모·브리핑), 데스크톱 = 두 쪽 펼침.
