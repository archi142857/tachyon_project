## 컴포넌트와 동작

- **날짜 머리**: 큰 날짜 숫자 + 연·월·요일, 오른쪽에 D-day 상자(`유기화학 중간 D-15`, 1.5px 테두리), 아래 2px 잉크 선.
- **할 일 줄**: [체크칸] [이름 + `약 2시간 · 지금 할 수 있음`(또는 `수업·자료 뒤`)] [마감 `내일 자정` — 여유가 1.5일 안쪽이면 빨강]. 끝내면 손으로 그린 ✓ + 이름 가로줄 + 빨간 동그라미 '끝' 도장, 토스트 `'…' 끝 [되돌리기]`(5초). 끝낸 것도 셋 아래에 남는다.
- **몰림 경고**: 이번 주 마감이 4개 이상이면 '오늘 할 일 셋' 옆에 빨간 손글씨 `이번 주 마감 5개 몰림!`.
- **오늘 시간(앱 홈)**: 시각(명조 굵게) + 출처 색 형광펜을 칠한 일정 이름 + 장소.
- **메모 줄**: 공책 줄마다 [시각] [손글씨 메모] [일정이 됐으면 `→ 토 11:00`]. 해석하는 동안 `…읽는 중`.
- **입력 줄**: 2px 밑줄, 손글씨 입력, `여기에 적기… (내일 3시 스터디)`, 남색 동그라미 펜 버튼. 위에 예시 칩(누르면 입력 칸에 채움).
- **포스트잇 확인 창**: `이대로 저장할까요?` + 이름·날짜·시각·장소(모르는 칸은 빨간 `?`) + [저장][고치기][취소]. 고치기 → 칸이 입력으로 바뀜. 저장 → 토스트 `내일 15:00 '스터디' 달력에 넣었어요 [되돌리기]`, 달력에 새 일정이 잉크 번지듯 나타남. 취소 → `메모로만 남겼어요. 밤 정리 때 다시 볼게요`. `role=dialog`.
- **토스트**: 종이 + 잉크 테두리 + 딱딱한 그림자, 5초, 되돌리기. `role=status`.
- **주간표**: 머리(날짜 숫자 + 요일, 오늘은 빨간 동그라미) → '마감' 줄(그날 마감 할 일을 분홍 테이프로) → 시간 칸(출처별 형광펜 띠, 중요는 빨간 테두리). 오늘 칸은 연노랑, 지금은 빨간 점선 + `지금`. 범례 줄. ‹ ›로 주를 넘기면(0~2주) 오른쪽 쪽이 넘어간다.
- **색인 탭**: 세로 글씨. 오늘 하늘·주간 민트·메모 분홍·브리핑 노랑. 지금 탭은 6px 튀어나옴(`aria-current`).
- **브리핑(아침 한 쪽)**: 작은 머리 `11월 10일 화요일 · 오늘의 한 쪽` → 큰 제목(형광 밑줄) `오늘은 '…'부터` → 까닭 한 문장 → 바쁜 정도(동그라미 5개) → 오늘 일정 → 먼저 할 것(번호) → 미뤄도 되는 것(손글씨) → 밤 정리 한 줄 `어젯밤 메모 2개 → 할 일 1개로 정리했어요`.

**작은 글자(원칙 76, 앱 12px)** — 마감 테이프 10.5px, 일정 칸 작은 글 10px, 시간 숫자·요일·메모 시각 11px. 폰 주간표 7칸(한 칸 약 42px)에서는 12px를 지키기 어렵다 → 폰은 칸에 이름만, 시각·장소는 눌러서 본다.

**그 밖**
- 바쁜 정도 동그라미 5개는 등급 표시다(원칙 13) → `일정 4시간 · 마감 2개`처럼 수치로.
- 할 일마다 `약 2시간`이다(원칙 14) → '약'은 화면에 한 번.
- 주간표가 월~일이고 주 단위로 넘긴다 → 앱은 오늘부터 7일(11-10). 넘김은 '다음 7일'.
- 동작 줄이기는 이미 지킨다(원칙 123). 주 넘김은 큰 이동이라 평소에도 짧게(앞 점검대로).
- 데스크톱 창 제목줄(신호등 단추)은 시안 틀이다. 앱에 넣지 않는다.
- 잘한 것: 점선 초점, 체크칸 `aria-label`(`… 끝내기`), 포스트잇 `role=dialog`, 토스트 `role=status`, 탭 `aria-current`, 주 넘김 `aria-label`, 출처 색 범례, 중요 일정은 색만이 아니라 테두리로도 표시.

## 앞 점검(캡처로 본 것)에서 고칠 것

- '색인 탭 약 30px' → 앱 26px, 데스크톱 30px.
