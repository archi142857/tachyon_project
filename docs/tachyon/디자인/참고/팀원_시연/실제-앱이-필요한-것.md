# 실제 앱 · 서버가 있어야만 되는 것

> 11월 11일 오후 · 시연 7판(PC · 모바일) 기준
> 시연 화면에서는 아래 기능이 모두 **가상으로** 움직입니다. 눌러 보면 되는 것처럼 보이지만, 보이는 자료는 지어낸 예시이고 새로 고치면 처음으로 돌아갑니다.
> 이 표는 "시연에서 보이는 것"과 "진짜로 만들 때 필요한 것"을 나란히 적은 것입니다.

## 1. 연결 (밖의 서비스에서 가져오기)

| 기능 | 시연에서 보이는 것 (가상) | 실제로 필요한 것 |
|---|---|---|
| eTL 한 번 눌러 연결 | 버튼 하나 → 세 단계가 0.7초씩 지나가고 "일정 17개 · 과제 6개를 찾았어요". 시간표에 강의실 · 교수님이 붙음 | 지금 학생이 직접 토큰을 받으려면 다섯 단계쯤 거쳐야 함. 한 번 누르기로 줄이려면 ① 브라우저 확장 프로그램이 로그인된 eTL에서 대신 받아 오거나 ② 학교가 승인한 로그인 연동(OAuth)이 있어야 함. 토큰을 안전하게 보관할 서버도 필요 |
| 강의실 · 교수님 성함 | 일정 토막을 누르면 장소 · 교수님이 나옴 (지어낸 값, 성함은 가림) | 지금 쓰는 eTL 자료 길에는 교수님 성함이 없음. 수강편람(강좌 검색) 자료를 따로 이어야 함. 강의실은 eTL 일정에 있을 때만 옴 |
| 구글 · 애플 캘린더 가져오기 | 마이페이지에서 '연결' → 일정 2개가 달력에 들어옴. '끊기'를 누르면 가져온 것만 빠짐 | 구글은 로그인 연동 심사(민감 범위)가 필요. 심사 전에는 캘린더 구독 주소(ICS)를 붙여 넣는 길만 가능. 애플은 구독 주소 방식 |
| 노션 연결 | '연결' → 노션 할 일 3개가 들어옴 | 노션 공개 통합(OAuth) 등록, 사용자가 어느 데이터베이스를 읽을지 고르는 화면, 주기적으로 다시 읽는 서버 작업 |
| 투두메이트 연결 | '연결' → 할 일 2개가 들어옴 | 투두메이트는 공개된 연결 길(API)이 없음. 실제로는 내보낸 파일을 올리거나 사진 · 글을 붙여 넣어 옮기는 방식만 가능 |

## 2. 학교 자료가 있어야 하는 것

| 기능 | 시연에서 보이는 것 (가상) | 실제로 필요한 것 |
|---|---|---|
| 졸업요건 탭 | eTL을 연결하면 영역별로 "들은 학점 / 채울 학점"과 다음 학기에 들을 과목 제안 (합계 130학점, 이수 내역은 지어낸 값) | ① 지금까지 들은 과목: eTL에는 이번 학기 강좌만 확실히 있음. 지난 학기 이수 내역은 성적 조회 자료를 잇거나 사용자가 성적표를 올려야 함 ② 학과 · 입학년도마다 다른 요건 표를 누군가 만들어 관리해야 함 ③ 틀리면 졸업에 영향이 가므로 "참고용 · 학사과 확인" 표시가 꼭 필요 |
| 튜터 | 유기화학 3장 한 과목만: 지어낸 요약과 질문 몇 개 | 강의 자료를 읽어 들이는 길(파일 올리기 또는 eTL 자료실), AI 쓰는 값, 강의 자료 저작권 문제(아직 답이 없음). "과제의 답은 만들지 않는다"는 원칙을 지키는 장치 |

## 3. 계정 · 서버가 있어야 하는 것

| 기능 | 시연에서 보이는 것 (가상) | 실제로 필요한 것 |
|---|---|---|
| 친구 · 그룹 · 멤버 넣고 빼기 | 지어낸 별명의 친구 목록, 요청 보내기 · 수락, 그룹 만들기 | 계정, 친구 요청을 주고받는 서버, 알림 |
| 다 같이 · 둘이 빈 시간 | 달력에 겹쳐 비는 때가 표시됨 (친구 일정은 지어낸 값) | 친구의 달력을 서로 볼 수 있다는 동의와 범위(바쁨/한가함만 보이게), 서버에서 겹침 계산 |
| 받은함 (친구 요청 · AI 제안 · 하루 한 질문) | 카드가 쌓여 있고 누르면 처리됨. "내일 질문 미리 보기" | 서버에서 날마다 도는 예약 작업, 푸시 알림, 질문에 답한 것을 기억하는 저장소 |
| 아침 브리핑 · 밤 정리 알림 | 화면 안에서만 보임 | 푸시 알림 권한, 정해진 시각에 보내는 서버 작업 |
| 저장 · 기기끼리 맞추기 | 없음 (새로 고치면 처음으로) | 계정과 데이터베이스. 지금 배포된 앱에는 이미 있음 |

## 4. AI가 실제로 읽고 판단해야 하는 것

| 기능 | 시연에서 보이는 것 (가상) | 실제로 필요한 것 |
|---|---|---|
| AI 제안: 메모가 어떤 할 일의 한 부분인지 | 낱말이 겹치면 "이 메모는 ○○의 한 부분 같아요" 카드 | 낱말 맞추기로는 뜻이 다른 것을 놓침. 실제로는 밤 정리 때 AI가 읽고 판단 (값이 듦) |
| AI 제안: 몰린 날 당기기 | 마감이 몰린 날을 찾아 "하루 당길까요?" 카드 | 규칙만으로 가능 (서버 없이도 됨). 다만 알림으로 먼저 알려 주려면 3번의 서버 작업이 필요 |
| 줄임말 알아듣기 ("공수2", "공수" → 공학수학 2) | 미리 넣어 둔 줄임말 표 + 받은함에서 "이 뜻이 맞나요?" 확인, 마이페이지에서 잊기 | 배포된 앱에는 과목 이름 줄임말 규칙이 이미 있음. 처음 보는 표현까지 알아들으려면 AI 판단 + 사용자가 확인한 것을 기억하는 저장소 |
| 나에 대해 아는 것 (이동 시간 · 저녁 시각) | 질문에 답하면 마이페이지에 쌓이고 지울 수 있음 | 저장소, 그리고 그 값을 실제 배정에 쓰는 계산 |

## 5. 기기 권한이 있어야 하는 것

| 기능 | 시연에서 보이는 것 (가상) | 실제로 필요한 것 |
|---|---|---|
| 노트북 · 폰 파일 정리 | "폴더 접근 허락하기 (가상)" → 지어낸 파일 6개를 과목별로 묶는 제안 → 옮기기 · 되돌리기 | 웹 페이지는 기기 저장소를 마음대로 못 봄. 노트북은 설치하는 프로그램, 폰은 앱이 필요 (아이폰은 앱끼리 파일을 거의 못 봄). "이름과 위치만 본다 · 지우지 않는다 · 되돌릴 수 있다"를 지키는 설계 |
| 집중 타이머 | 화면 안에서 줄어듦 (시연은 1초 = 1분) | 화면을 꺼도 도는 타이머와 끝났다는 알림은 앱 또는 알림 권한이 필요 |

## 6. 따로 아무것도 필요 없는 것 (화면만 고치면 됨)

실제 앱에 옮길 때 서버 · 권한 없이 화면 작업만으로 되는 것들입니다.

- 일정 토막을 누르면 정보가 나오는 시트 (장소 · 교수님 값이 있을 때)
- 집중 시간 조절 (− / +)
- 첫 화면 질문의 예시 그림
- 방향키: ← → 카드 · 달력 넘기기, ↑ ↓ 탭 옮기기
- 엔터 = 메모 칸으로
- 사이드바 아래 글 · "메모 쓰기" 버튼 없애기
- 밀도 고리 (달력 주 머리)
- 빈 시간에 할 일을 직접 넣기 · 예상 시간과 상관없이 여러 번 넣기
- 라이트 / 다크가 이어지며 바뀌는 전환
- 떠 있는 입자
- 시작 튜토리얼 (메모 → 할 일 고리)
- 마이페이지 화면 틀
- 세 번째 미루기에 묻는 말 ("세 번 미뤘어요. 안 해도 될까요?")

## 한 줄 정리

사람들이 쓰게 만드는 데 가장 중요한 **eTL 한 번 누르기**가 가장 어렵습니다. 확장 프로그램을 만들거나 학교의 승인을 받아야 하고, 교수님 성함은 수강편람을 따로 이어야 합니다. 나머지 연결(캘린더 · 노션)은 등록 · 심사 절차의 문제이고, 화면 쪽 기능(6번)은 바로 옮길 수 있습니다.
