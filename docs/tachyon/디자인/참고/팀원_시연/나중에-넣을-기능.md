# 나중에 넣을 기능

사용자가 "나중에 넣을 기능"이라고 말해 둔 것들입니다. 아직 시연에도 실제 앱에도 넣지 않았습니다.

## 11-11 17:48에 적어 둔 것

1. **시험 플랜 되돌아보기**
   - 시험 플랜을 짜 준다.
   - 시험이 끝나면 "이 플랜이 괜찮았는지" 피드백을 받는다.
   - 받은 피드백은 다음 시험 플랜을 짤 때 쓴다.

2. **할 일 타이머로 예상 시간 고치기**
   - 할 일을 시작할 때 타이머를 잰다.
   - 예상 시간보다 얼마나 넘쳤는지, 얼마나 남았는지 확인한다.
   - 그 차이를 다음에 일정을 짤 때(빈 시간에 자동으로 넣을 때) 반영한다. 예: 문제풀이가 늘 예상의 1.5배 걸렸으면 다음부터 그만큼 길게 잡는다.

## 넣을 때 볼 것

- 2번은 지금 시연의 "집중 50분 시작" 타이머와 "자동으로 넣은 자리"에 바로 이어 붙일 수 있습니다(실제로 걸린 시간 기록 → 예상 시간 고치기).
- 화면을 꺼도 도는 타이머는 앱 또는 알림 권한이 있어야 합니다([실제-앱이-필요한-것.md](실제-앱이-필요한-것.md) 5번).
