# 테마 만드는 법

테마는 **색 · 모서리 · 글꼴 값 묶음**입니다. 화면 구조(오늘 화면의 하루 고리 · 타임라인 · 할 일, 주간 달력, 메뉴)는 테마가 바뀌어도 그대로입니다.

- 바꾸는 곳: 앱 **메뉴 → 테마**
- 고른 테마와 가져온 테마는 **그 기기에만** 기억합니다(브라우저 저장소 `tachyon_theme` · `tachyon_themes`). 서버로 보내지 않고 `schema.sql`도 그대로입니다.
- 기본은 지금까지 쓰던 **차분한 종이**이고, 아무것도 안 고르면 전과 똑같습니다.

> 11-11 사람이 기본 옷을 디자인 ③ **바우하우스**(칸딘스키 점·선·면)로 바꾸기로 했습니다. 화면 세션이 [tokens.css](tokens.css)를 옮기면 기본은 바우하우스, 차분한 종이는 둘째 테마가 됩니다(값은 그대로). 그때 아래 표와 '적지 않은 값' 문장도 바우하우스로 바뀝니다.

## 지금 들어 있는 테마

| 이름 | 모습 | 어디서 왔나 |
|---|---|---|
| 차분한 종이 (기본) | 종이색 바탕, 남색 강조 | 디자인 가이드 ② — 값은 `web/src/styles.css` 맨 위 |
| 입자 밤 | 검은 바탕에 보라 · 청록 | 팀원 시연 9판의 어두운 쪽 |
| 입자 낮 | 같은 보라 · 청록을 밝은 바탕에 | 팀원 시연 9판의 밝은 쪽 |
| 벤토 위젯 | 회색 바탕에 흰 타일, 둥근 모서리 | 처음 만든 시안 묶음 |
| 조용한 갤러리 | 흰 바탕, 각진 모서리, 자홍색 한 점 | 처음 만든 시안 묶음 |
| 호박색 터미널 | 검은 바탕에 호박색 글자, 고정폭 글꼴 | 처음 만든 시안 묶음 |

## 새 테마를 넣는 두 가지 길

### 1. 앱에 붙여 넣기 (코드 없이, 그 기기에만)

1. 메뉴 → 테마 → **지금 값 채우기**를 누르면 지금 테마의 값이 글로 채워집니다.
2. `name`을 새 이름으로 바꾸고 색 값을 고칩니다. (이 글을 AI에게 주고 "색만 숲 느낌으로 바꿔 줘"라고 해도 됩니다.)
3. **가져오기**를 누르면 목록에 들어가고 바로 바뀝니다. 목록의 '지우기'로 뺍니다.

```json
{
  "name": "예시 숲",
  "dark": false,
  "vars": { "--bg": "#eef3ea", "--card": "#fbfdf8", "--accent": "#2f6b3a" }
}
```

- `name`: 1~20자. 들어 있는 테마와 같은 이름은 못 씁니다.
- `dark`: 어두운 테마면 `true`.
- `vars`: 아래 '값 이름'에 있는 것만 받습니다(모르는 이름은 빼고 몇 개 뺐는지 알려 줍니다). **적지 않은 값은 차분한 종이 값**을 씁니다.
- 값에는 색 · 길이 · 글꼴 이름에 쓰는 글자만 됩니다. 바깥 주소를 부르는 값(`url(...)` 등)은 받지 않습니다.
- 가져온 테마는 20개까지입니다.
- 이 길은 글자 대비를 재 주지 않습니다. 글자가 잘 안 보이면 색을 고쳐 다시 가져오세요(같은 이름이면 덮어씁니다).

### 2. 모두가 쓰는 테마로 넣기 (코드)

1. `web/src/themes.css`에 블록 하나를 더합니다. 있는 블록을 복사해 값만 바꾸면 됩니다.
2. `web/src/themes.js`의 `BUILT_IN`에 같은 이름을 적습니다.
3. `web/`에서 `npm test` — `themes.test.js`가 **빠진 값**과 **글자 대비**(글자 4.5:1, 선 · 초점 3:1)를 잽니다. 떨어지면 어느 테마의 어느 값인지 알려 줍니다.
4. `npm run dev` → `http://localhost:5173/?example` → 메뉴 → 테마에서 눈으로 봅니다.

## 화면까지 바뀌는 테마: 입자 · 종이

메뉴 → 테마 목록 맨 아래의 '입자'(어두운)와 '종이'(밝은)는 색만이 아니라 화면 틀까지 시연 9판 모양으로 바꿉니다. 다른 테마를 고르면 원래 화면으로 돌아옵니다.

- 화면 파일은 `web/src/ours/`에만 있습니다(`OursMain` 틀 · `OursToday` 오늘과 할 일 · `OursCal` 주·월 달력 · `OursRing` 고리 · `OursStart` 로그인과 첫 설정 · `ours.css`). 원래 화면 파일과는 `themes.js`의 `SKINS`, `ThemeSheet.jsx`의 단추 둘, `Dashboard.jsx`와 `App.jsx`의 갈림 하나씩으로만 이어집니다.
- 색은 '입자 밤' · '입자 낮' 값 묶음을 같이 입힙니다. 그래서 고치기 창 · 메뉴 창 · 같이 쪽 · 동선 지도처럼 원래 부품을 그대로 부르는 곳도 색이 맞습니다.
- `SKINS`의 이름은 `BUILT_IN`에 넣지 않습니다(`themes.test.js`가 값 묶음 이름만 셉니다).
- 아직 이 화면에 없는 것: 받은함(아침 브리핑) 쪽, 할 일 고리 카드, 처음 길잡이, 집중 타이머, 나눠 둔 몫 목록, 달력의 '+ 일정' · '다 같이 빈 시간' 단추, 달력 위 동선 선. 이 기능들은 원래 테마에서 그대로 씁니다.

## 정해 둔 것

- 테마 이름은 모습을 말하는 한국어 낱말로 짓습니다. 다른 서비스 이름이나 상표를 흉내 내지 않습니다.
- 글꼴은 기기에 이미 있는 것만 씁니다(새 글꼴 파일을 받지 않습니다).
- 테마는 값만 바꿉니다. 부품 모양을 테마마다 따로 고치는 일(가이드 2~4순위)은 이 일에 들어 있지 않습니다.
