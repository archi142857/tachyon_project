# 테마 만드는 법

테마는 **색 · 모서리 · 글꼴 값 묶음**입니다. 화면 구조(오늘 화면의 하루 고리 · 타임라인 · 할 일, 주간 달력, 메뉴)는 테마가 바뀌어도 그대로입니다.

- 바꾸는 곳: 앱 **메뉴 → 테마**
- 고른 테마와 가져온 테마는 **그 기기에만** 기억합니다(브라우저 저장소 `tachyon_theme` · `tachyon_themes`). 서버로 보내지 않고 `schema.sql`도 그대로입니다.
- 기본은 **바우하우스**(11-11 사람이 고름)이고, 아무것도 안 고르면 이것입니다.

## 새 테마를 넣는 두 가지 길

### 1. 앱에 붙여 넣기 (코드 없이, 그 기기에만)

1. 메뉴 → 테마 → **지금 값 채우기**를 누르면 지금 테마의 값이 글로 채워집니다.
2. `name`을 새 이름으로 바꾸고 색 값을 고칩니다. (이 글을 AI에게 주고 "색만 숲 느낌으로 바꿔 줘"라고 해도 됩니다.)
3. **가져오기**를 누르면 목록에 들어가고 바로 바뀝니다. 목록의 '지우기'로 뺍니다.

```json
{
  "name": "예시 숲",
  "dark": false,
  "vars": { "--bg": "#eef3ea", "--card": "#fbfdf8", "--accent": "#2f6b3a" }
}
```

- `name`: 1~20자. 들어 있는 테마와 같은 이름은 못 씁니다.
- `dark`: 어두운 테마면 `true`.
- `vars`: 아래 '값 이름'에 있는 것만 받습니다(모르는 이름은 빼고 몇 개 뺐는지 알려 줍니다). **적지 않은 값은 바우하우스 값**을 씁니다.
- 값에는 색 · 길이 · 글꼴 이름에 쓰는 글자만 됩니다. 바깥 주소를 부르는 값(`url(...)` 등)은 받지 않습니다.
- 가져온 테마는 20개까지입니다.
- 이 길은 글자 대비를 재 주지 않습니다. 글자가 잘 안 보이면 색을 고쳐 다시 가져오세요(같은 이름이면 덮어씁니다).

### 2. 모두가 쓰는 테마로 넣기 (코드)

1. `web/src/themes.css`에 블록 하나를 더합니다. 있는 블록을 복사해 값만 바꾸면 됩니다.
2. `web/src/themes.js`의 `BUILT_IN`에 같은 이름을 적습니다.
3. `web/`에서 `npm test` — `themes.test.js`가 **빠진 값**과 **글자 대비**(글자 4.5:1, 선 · 초점 3:1)를 잽니다. 떨어지면 어느 테마의 어느 값인지 알려 줍니다.
4. `npm run dev` → `http://localhost:5173/?example` → 메뉴 → 테마에서 눈으로 봅니다.
5. 테마를 바꿀 때 덮는 로딩 화면을 `themes.js`의 `LOADER` · `LOADER_CLASS`와 `loader.css`에 하나 더합니다(사람 11-13 01:48 "각 테마별 로딩 화면"). 테마 창(`ThemeSheet.jsx`)에 단추가 있는지도 봅니다.

## 값보다 더 바뀌는 테마: 입자 · 그림 테마

자리 · 내용 · 기능은 모든 테마가 같고, 아래 테마는 값 묶음에 더해 **모양 층**을 얹습니다. 모양 층의 규칙은 모두 그 테마의 `html[data-theme='이름']` 안에서만 걸려 다른 테마를 건드리지 않습니다.

- **입자**: `web/src/nine.css`(시연 9판 모양), 하루 고리는 `DayRing.jsx`의 `ParticleRing`.
- **그림 테마 넷**(태양계 · 오선지 · 원자 모형 · 뉴모피즘, 사람 11-13 02:47 "실제 앱 테마에 넣어줘"):
  - 값 = `themes.css`, 모양 층(칸 · 단추 · 일정 칸 · 할 일 동그라미 · 적기 칸 · 고리 범례) = `web/src/looks.css`.
  - 하루 고리 · 화면 뒤 그림 = `web/src/components/art/`(테마마다 고리 파일 하나, `Backdrop.jsx`, `art.css`). `DayRing.jsx`가 테마 이름으로 고리를 고르고, `Dashboard.jsx`의 `ThemeBackdrop`이 맨 뒤에 그림을 깝니다.
  - 테마 이름 목록 = `themes.js`의 `ART_THEMES` = `components/art/index.js`의 `RINGS` 이름(`design/rings.test.jsx`가 같은지 잼).
  - 시안 쪽(개발자용) `web/design/`도 같은 `components/art`를 씁니다 — 고리를 고치면 시안과 앱이 같이 바뀝니다.

## 정해 둔 것

- 테마 이름은 모습을 말하는 한국어 낱말로 짓습니다. 다른 서비스 이름이나 상표를 흉내 내지 않습니다.
- 글꼴은 앱 안에 싣습니다(바깥 글꼴 주소를 부르지 않음, OFL 글꼴만). npm `@fontsource` 묶음을 `main.jsx` · `components/art/fonts.js`에서 부르고, 값에는 그 글꼴 이름만 적습니다(`--font-head: 'Hahmlet Variable', …`). 글자 범위별로 나뉘어 그 테마를 고를 때 쓰는 글자만 받습니다.
- 값으로 되는 것은 값으로 합니다. 값으로 안 되는 모양만 모양 층에 적고, 거기서도 글자색은 대비를 잰 값(`--ev-text` 등)을 씁니다.
