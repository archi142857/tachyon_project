# 캘린더 주소(ICS) 찾는 법 — 첫 설정 화면용 (11-09)

첫 설정 화면에는 'ICS 주소 칸 3개(eTL·구글·애플)'가 있고, 칸마다 주소 찾는 법이 한 줄씩 붙는다. 이 문서에는 그 문구와, 붙여 넣은 주소를 서버가 다루는 규칙(제안)을 적는다. [인수인계](인수인계.md)의 열린 질문 'eTL 웹에서 캘린더 피드 주소를 찾는 길'에 대한 답이기도 하다.

## 칸 아래 한 줄

| 칸 | 한 줄 안내 | 할 수 있는 곳 |
|---|---|---|
| eTL | eTL → 왼쪽 '캘린더' → 오른쪽 아래 '캘린더 피드' → 주소 복사 | PC 웹 (앱은 아래 '자세히') |
| 구글 | 구글 캘린더 → 설정 → 내 캘린더 이름 → '캘린더 통합' → 'iCal 형식의 비공개 주소' 복사 | PC 웹만 (폰 앱에는 없음) |
| 애플 | 아이폰 캘린더 → 아래 '캘린더' → 캘린더 옆 ⓘ → '공개 캘린더' 켜기 → '링크 공유' → 복사 | 아이폰·맥·iCloud.com |

'자세히'를 누르면 아래 단계가 펼쳐지게 한다.

## 자세히

### eTL (myETL = Canvas)

1. PC에서 eTL에 로그인한다.
2. 왼쪽 메뉴에서 '캘린더'를 누른다.
3. 오른쪽 아래(작은 달력 밑)에서 '캘린더 피드'를 누른다.
4. 뜬 창의 주소를 복사한다. 주소는 `https`로 시작하고 `.ics`로 끝난다.

- 휴대폰 앱(Canvas 학생 앱): 캘린더 → 오른쪽 위 ⋮ → 캘린더 피드.
- 이 주소에는 마감이 있는 과제만 들어 있다(11-09 확인). 공지, 강의자료, 마감 없는 과제는 없다.
- 메뉴 이름은 Canvas 기준이다. 실제 eTL 화면은 로그인해야 보여서 아직 못 봤다. 이름이 다르면 이 문서를 고친다.

### 구글 캘린더

1. PC 브라우저로 calendar.google.com에 들어간다. 폰 앱에는 이 메뉴가 없다.
2. 오른쪽 위 톱니바퀴 → 설정.
3. 왼쪽 '내 캘린더의 설정'에서 캘린더 이름을 누른다.
4. '캘린더 통합'까지 내려가서 'iCal 형식의 비공개 주소'를 복사한다.

- 'iCal 형식의 공개 주소'와 헷갈리지 않게 한다. 공개 주소는 캘린더를 공개로 바꾸지 않았으면 비어 있다.
- 캘린더가 여러 개면 주소도 캘린더마다 따로 있다. 1단계에서는 칸 하나에 기본 캘린더만 받는다.
- 학교·회사 계정은 관리자가 막아 두면 이 주소가 보이지 않는다. 그럴 때는 개인 구글 계정 캘린더를 쓰거나 건너뛴다.
- 노션 캘린더는 구글 캘린더를 보여 주는 것이라 구글 주소를 넣는다. 삼성 캘린더도 일정을 구글 계정에 저장하고 있으면 구글 주소로 된다.

### 애플(iCloud) 캘린더

1. 아이폰 '캘린더' 앱을 열고 아래쪽 '캘린더'를 누른다.
2. iCloud 아래에서 넣을 캘린더 옆 ⓘ를 누른다.
3. '공개 캘린더'를 켜고 '링크 공유' → '복사'를 누른다.

- 맥에서는 캘린더 앱에서 캘린더 이름을 오른쪽 클릭 → 캘린더 공유 → 공개 캘린더. iCloud.com 캘린더에서도 된다.
- 주소가 `webcal://`로 시작한다. 그대로 붙여도 서버가 `https://`로 바꾼다.
- '공개'라서 주소를 아는 사람은 누구나 볼 수 있다. 주소는 길어서 짐작하기 어렵다. 그만 쓰려면 '공개 캘린더'를 끈다. 그러면 주소가 더는 열리지 않는다.
- iCloud 캘린더가 아니라 '나의 iPhone' 캘린더는 공개할 수 없다.

### 그 밖

- 삼성 계정에만 저장된 삼성 캘린더 일정, 네이버 캘린더 등은 1단계에 칸이 없다. 2단계 안드로이드 앱에서 폰 캘린더를 직접 읽을 때 다룬다.
- 네이버 캘린더도 iCal 주소를 낸다고 하는데, 메뉴 경로는 확인하지 않았다.

## 서버 규칙 (제안, 서버 세션이 정함)

이 주소들은 **비밀번호와 같다**. 주소만 있으면 누구나 그 캘린더를 읽을 수 있다.

1. **다듬기**: 앞뒤 공백을 지우고, `webcal://`은 `https://`로 바꾼다.
2. **모양 확인**: 1단계에서는 아는 곳의 주소만 받는다. 서버가 아무 주소나 대신 받아 오는 구멍을 막기 위해서다.

   | 칸 | 받는 모양 |
   |---|---|
   | eTL | `https://myetl.snu.ac.kr/`로 시작하고 `.ics`로 끝남 (Canvas는 보통 `/feeds/calendars/….ics`) |
   | 구글 | `https://calendar.google.com/calendar/ical/…/private-…/basic.ics` |
   | 애플 | `https://p…-caldav.icloud.com/published/…` |

   - 모양이 틀리면 저장하지 않고, 칸 아래에 무엇이 틀렸는지 한 줄로 보여 준다.
   - 구글 주소에 `/public/`이 들어 있으면 '비공개 주소를 넣어 주세요'라고 보여 준다.
3. **바로 받아 보기**: 붙여 넣자마자 한 번 받아 보고 결과를 보여 준다. 예: '과제 3개를 찾았어요', '이 주소로 읽지 못했어요'. 받은 내용에 `BEGIN:VCALENDAR`가 없으면 실패로 본다.
4. **저장**: 암호화해서 넣는다(소통판 11-09 schema 답 1의 `feeds` 표). 로그, 오류 보고, GitHub 이슈, 화면 어디에도 주소 전체를 남기지 않는다. 화면에는 `myetl.snu.ac.kr/…a1b2.ics`처럼 끝 4자만 보인다.
5. **주소가 죽으면**: 404·401이 오거나, 구글에서 '재설정'을 했거나, 애플에서 '공개'를 껐을 때다. 그 주소 수집을 멈추고 화면에 '이 캘린더 주소가 더 이상 열리지 않아요 → 다시 붙이기'를 띄운다.
6. **주소를 지우면**: 그 주소에서 온 일정도 같이 지운다.

## 아직 확인할 것 (사람, 1분)

- eTL 화면의 '캘린더 피드' 메뉴 이름과 위치. 로그인해야 보인다.
- eTL 피드 주소의 실제 모양. eTL 프로필의 `calendar.ics` 값을 보면 된다. 주소 자체는 저장소에 적지 않는다.
