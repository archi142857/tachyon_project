## ChatGPT Edu에 Tachyon 붙이기 (MCP, 11-09 조사)

MCP(Model Context Protocol)는 ChatGPT 같은 AI가 바깥 서비스의 기능('도구')을 불러 쓰게 하는 약속이다. ChatGPT 화면에서는 '앱'(전에는 '커넥터')이라 부르고, 2026-07부터는 스킬과 앱을 묶은 '플러그인'으로도 나온다.

**OpenAI 도움말에서 확인한 것** (11-09 기준, 베타라 바뀔 수 있음)
- 직접 만든 MCP 앱은 ChatGPT Business·Enterprise·Edu에서 쓸 수 있고, 만드는 것은 웹에서 한다.
- **Edu는 워크스페이스 관리자가 먼저 열어 줘야 한다.** 관리자가 워크스페이스 설정의 Permissions & Roles → Connected Data → 'Developer mode / Create custom MCP connectors'를 켜고, 역할별 권한(RBAC)으로 누구에게 줄지 고른다. 개발자 모드를 열어 주는 것은 관리자·소유자만 한다.
- 권한을 받은 사람은 자기 설정에서 개발자 모드를 켜고(설정 → 앱 → 고급 설정, 새 화면은 설정 → 보안 및 로그인), 앱(또는 플러그인) 만들기에 MCP 서버 주소를 넣는다. 이렇게 만든 앱에는 'Dev' 표시가 붙고, 게시 전에는 만든 사람만 쓴다.
- 워크스페이스 전체(서울대 구성원 모두)에 게시하는 것도 관리자·소유자만 한다. Enterprise·Edu에서는 플러그인과 그 안의 앱이 처음엔 꺼져 있다.
- 로그인: 서버가 OAuth(서비스 계정으로 로그인해 허락하는 방식)를 쓰면 갱신 토큰(`offline_access`)을 내줘야 사용자가 자꾸 다시 로그인하지 않는다. 인증 없이 붙는 서버도 된다.

**우리에게 뜻하는 것**
1. 서울대 ChatGPT Edu의 관리자는 정보화본부다. 이 공모전을 여는 곳이기도 하다.
2. 먼저 사람이 학교 계정에서 개발자 모드 칸이 보이는지 1분 확인한다(11-09 archi142857에게 부탁, 11/16 회의 전).
   - 보이면: 3단계에 넣는다. 서버가 `/mcp` 주소를 열고, 각자 자기 계정에 'Dev' 앱으로 붙여 시연 영상을 찍는다.
   - 안 보이면: 정보화본부에 '공모전 출품작을 학교 ChatGPT Edu에 붙여 보고 싶다, 개발자 모드 권한을 받을 수 있나'를 물을지 사람이 정한다(문의 글 초안은 컨셉이 쓴다). 11/16 회의까지 길이 안 보이면 접는다.
3. 심사위원이 ChatGPT Edu에서 직접 써 보려면 정보화본부가 워크스페이스에 게시해야 한다. 신청서에는 '정보화본부가 게시하면 서울대 구성원 누구나 ChatGPT Edu에서 Tachyon을 부를 수 있다'고 쓸 수 있다.

**서버 쪽 메모** (3단계에 하게 되면. 정하는 것은 서버 세션)
- 주소 `https://tachyon.tachyon-project.workers.dev/mcp`, 전송은 스트리밍 HTTP(MCP 표준 방식).
- 도구는 둘부터: 오늘 브리핑 읽기(읽기), 메모 넣기(쓰기, 넣은 메모는 앱의 확인 창을 그대로 거친다). 여유 있으면 다가오는 할 일·일정 읽기.
- 로그인은 두 길:
  - 빠른 길: 사용자별 비밀 주소 + 인증 없음. 자기 계정의 'Dev' 앱으로만 쓸 때. 캘린더 내보내기 주소처럼, 주소가 새면 새로 만들 수 있게 한다.
  - 게시까지 가면: OAuth 2.1. 지금의 구글 로그인 위에서 Worker가 OAuth 제공자 노릇을 한다(Cloudflare `workers-oauth-provider` 같은 라이브러리).
- [개인정보처리방침 초안](개인정보처리방침_초안.md) 2절 아래에 'ChatGPT Edu에서 부를 때만, 그 요청에 필요한 것이 그 사람의 ChatGPT Edu 대화로 간다'는 줄 자리를 뒀다.
