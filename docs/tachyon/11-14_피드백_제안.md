# 11-14 피드백 중 사람이 정할 것 (제안)

> 11-14 새벽 피드백 묶음 중 코드로 바로 하지 않은 것. 각 줄의 **정할 것**에 답이 오면 그대로 만든다.
> 값은 '어림'이라고 적은 것은 잰 숫자가 아니다. 진짜 값은 앱 '개발자 보기'(worker/11_admin.js)의 모델별 토큰·값으로 확인한다.

## 메모 길이로 모델 나누기 · 요금제

- **한 것(코드):** 120자 이상이거나 3줄 이상인 메모만 팝업 읽기를 큰 모델(Sonnet 5.5)로, 나머지는 작은 모델(Haiku 5.5) 그대로(`worker/3_memo_popup.js` `isLongMemo`). 피드백의 'SLM'은 지금 쓰는 작은 모델(Haiku)로 대신했다. 우리가 따로 돌리는 작은 모델 서버는 없다. 폰 안에서 도는 작은 모델(짧은 메모는 서버로 안 보냄)은 지금 앱이 웹 화면이라 못 돌리고, 네이티브 앱이 생긴 뒤에 볼 일이다.
- **값 셈(어림):** 한 번 = 입력 토큰 × 입력값 + 출력 토큰 × 출력값. 값표(11_admin.js): Haiku $0.10 / $0.50, Sonnet $2 / $10 (백만 토큰당). 팝업 한 번을 입력 3,000 · 출력 150~640토큰으로 치면 짧은 메모 약 $0.0004, 긴 메모 약 $0.01 — 약 25배. 지금은 구독에 딸린 월 API 크레딧 $200 안에서만 쓰고 넘으면 멈춘다(돈은 안 나감).
- **요금제 모양(제안):**
  | | 무료 | 유료 |
  |---|---|---|
  | 짧은 메모 팝업 | 그대로 | 그대로 |
  | 긴 메모(큰 모델) | 하루 몇 개까지 | 넉넉히 |
  | 사진·파일 붙이기 | 없음 또는 작게 | 있음 |
  | 시험 준비(튜터) | 없음 | 있음(아래) |
- **정할 것:** ① 유료를 둘지, 값 ② 무료의 긴 메모 하루 개수 ③ 개발자 보기의 실제 값을 1주 본 뒤 정할지.

## 메모에 사진·영상·파일 붙이기

- **만들 모양(제안):** 이미 있는 R2(시간표 사진)에 `memo/<사용자>/<메모>/<파일>`로 둔다. 한 파일 10 MB · 사람당 200 MB까지(영상은 길이 대신 크기로 막음). 사진·PDF는 AI가 읽고, 영상은 저장만.
- **걸리는 것:** 메모 표에 붙인 파일 칸(또는 새 표)이 필요 → **DB 바꿈 = 게시판 합의**. 개인정보처리방침에 '메모 첨부 파일 보관'을 더해야 한다. Workers 무료 CPU 10 ms로는 큰 파일 처리(바꾸기·자르기)를 못 한다 → 그대로 저장만.
- **정할 것:** ① 크기 한도 ② 영상까지 받을지 ③ DB 칸 추가 합의.

## Claude API를 친구와 같이 쓰기

- 키는 지금도 Cloudflare 비밀값에만 있고, 배포된 앱을 쓰는 사람은 모두 그 키로 AI를 쓴다(따로 할 일 없음).
- 친구가 **자기 컴퓨터에서 개발**할 때: 키를 채팅·파일로 넘기지 않는다. 방법 ① 친구를 Cloudflare 계정 멤버로 넣고 `npx wrangler dev --remote`로 배포 환경 비밀값을 그대로 쓰기 ② 친구가 자기 키를 저장소 맨 위 `.dev.vars`(.gitignore에 있음, 커밋 안 됨)에 두고 `npx wrangler dev`.
- **정할 것(사람 손):** ①이면 계정 주인이 Cloudflare → Manage Account → Members에서 친구 초대.

## 폰 홈 화면 위젯(할 일 · 오늘 일정)

- 안드로이드 위젯은 앱 껍데기(Capacitor) 안에 Kotlin 코드가 따로 필요하다: 위젯 화면(XML) + 위젯이 서버 목록을 받아 오는 코드 + 로그인 쿠키 나눠 쓰기. 지금 APK는 CI가 `npx cap add android`로 매번 새로 만드므로, 위젯 파일을 `app/android-res/`에 두고 android.yml이 복사하게 한다.
- 이 노트북에서 안드로이드 빌드·에뮬레이터를 돌려 확인해야 해서(무거운 일) 이번 묶음에서 뺐다.
- **정할 것:** 11/25 동결 전에 넣을지(넣으면 할 일 위젯 하나부터).
