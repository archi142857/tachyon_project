# 합친 앱 — 기능별 결정 (11-13 사람)

사람(dhsrua555)이 기능 19개를 '내 버전(9판 시안·입자 테마) / 친구 버전(지금 기본 화면) / 섞기 / 보류'로 골랐다. 고를 때 본 비교 화면은 claude.ai 아티팩트라 팀 세션에서는 열리지 않으므로 여기에 옮긴다. 따옴표 안은 사람이 적은 메모 그대로다.

## 1. 레이아웃은 하나 (사람: "레이아웃을 통일해야해")

- 테마는 겉모양(색·글꼴)만 바꾸고, 화면 배치는 모든 테마가 지금 기본 화면 하나를 쓴다.
- 그래서 '입자'·'종이' 테마의 따로 그리던 화면(`web/src/ours/`)을 뺐다. 그 이름을 골라 둔 기기는 '입자 밤'·'입자 낮' 색 테마로 옮겨진다.
- 9판에서 살릴 기능은 아래 '내 버전'·'섞기'대로 기본 화면 안에 넣는다.

## 4. 열다섯 말고 사람이 더 준 피드백 (11-13 00:48)

컨셉 00:35 글의 1~15와 같은 목록을 사람이 다시 보내면서 아래를 더했다.

16. 고리를 딱히 누르지 않는 것 같다.
17. 주 / 월 달력 바꾸기를 더 눈에 띄게.
18. 메모 쪽에 파일 · 사진도 — '나와의 채팅'처럼.
19. 친구 일정 보기(공개 설정도), 일정은 없지만 안 되는 시간은 회색, AI가 제안한 시간이 되는 시간인지 안 되는 시간인지 확인하고 정하기.

나눔 제안(정하는 건 각 세션):
- 16 → 디자인 · 화면: 고리는 '보는 것'으로 두고, 누르는 일은 타임라인 · 목록에 맡긴다. 고리를 눌러야 하는 기능(바깥 점 등)은 글 단추를 같이 둔다.
- 17 → 화면: 달력 쪽 맨 위에 큰 '주 | 월' 단추.
- 18 → 서버(파일 보관) + 화면, 실사용 뒤.
- 19 → 서버(공개 범위 · 안 되는 시간 저장) + AI(제안 전에 확인) + 화면(회색 칸), 실사용 뒤.
- 6 초대: 별명 · 친구 코드로 찾기에 dhsrua555 쪽은 동의한다. 연락처(전화번호)로 찾기는 개인정보라 사람에게 다시 묻는다.
