## 검증

검증 명령(일반 Python 환경):

```sh
python scripts/validate_requirements.py
python scripts/validate_requirements.py --strict-facts
python -m pytest tests/test_validate_requirements.py
python -m pytest
```

`validate(data, schema=None)`는 형식·의미 규칙을, `verify_provenance(data, base_dir=None)`는 원본 SHA256·필드 보존을 검사한다. CLI는 둘 다 실행한다. 기본 종료코드0, 형식/보존 오류1, strict-facts에서 미해결이 있으면2다. strict-facts는 온라인 검증이 아니며 사실 검토와 계산 준비를 합한 needs_check를 검사한다.

현재 형식·의미·보존 검사는 통과했다. SHA256은 `6d3dda941932761d5598fb1f6701a7edbbdb62e60edd5d673ff8d5647a57c9a6`이며 외부 제공본과도 일치한다. 별도의 jsonschema 라이브러리로 스키마 자체와 입력을 검사해 통과했다.

전체 테스트는 최초 실행에서 프로젝트 임시 경로 권한 오류가 발생했다. 앱에 포함된 Python3.12와 사용자 임시 폴더의 테스트 도구·격리 임시 경로를 사용해 재실행했다. 실행 명령은 `python -m pytest -p no:cacheprovider --basetemp <사용자 임시 폴더의 Research 전용 경로> -q`다. 테스트 도구를 저장소의 런타임 의존성으로 추가하지 않았다. 최종 수치는 아래 실행 결과에 기록한다.
