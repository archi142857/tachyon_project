## 보고를 읽는 기준

- 자료 1.0의 90항목은 사실 확인 40 + 미확정 50입니다. 확인 필요·수동 검토 85 = 미확정 50 + 사실 확인됐으나 계산 조건 미구조화 등 35이며, 나머지 5만 명시 목록 계산 대상입니다.
- 기존 전체 테스트 148개는 자료 생성 38 + 이수내역 78 + 규정 자료 32입니다. 이번 재실행 148 passed, 9 subtests passed. 이후 작성 중인 2-C·모의 연결·시연 테스트의 통과 근거로 사용하지 않습니다.
- 초기 Planner 145개와 Research 최종 148개는 시점이 다릅니다. 역할별 최초 보고의 미커밋 문구를 현재 상태로 복사하지 않습니다.
- 시작 프롬프트만 있는 경우 실행·완료로 세지 않습니다. 미등록 보고와 미착수 기능은 다릅니다. 파일이 생겨도 해당 검사와 완료 보고 전에는 진행 중으로 둡니다.
- 사용자 자율 진행 지시에 따라 필요한 요청·결과는 지정된 세션끼리 직접 전달합니다. 내부 배정된 일을 사용자에게 다시 복사하도록 요구하지 않습니다. 커밋·푸시·학교 회신·외부 발송·실제 공개 조건은 유지합니다.
