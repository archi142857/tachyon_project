## 완료한 산출물

- `demo/inputs/animal.json`, `biology_double.json`, `chemical_double.json`: 실제 로컬 편람 과목에 지어낸 이수 상태를 붙인 예시. 실제 학생·성적·식별자는 없음.
- `demo/가상_입력.md`, `demo/사용_흐름.md`: 입력→한 번 확인·정정→범위를 구분한 결과→시간표 미준비→향후 비교 흐름. GPT 대화 설계이며 실제 GPT 실행 화면이 아님.
- `demo/독립_기대값.md`: 입력과 공식 근거를 읽고 수작업으로 고정한 기대값. 선수·중복·미확인과 시간표·방향별 이동 경계 포함. 실행 출력에서 정답을 복제하지 않음.
- `tests/test_end_to_end.py`: 3사례의 정리·요건 대조·정정·단일전공과 다전공 인정 경계 통합 검사12개.

- `docs/검증_결과.md`: 계산값·검사 결과·미실행 범위·재현 명령.

이번 커밋에 포함 가능한 Frontend 소유 범위: **demo/의 위 파일 전체, tests/test_end_to_end.py, docs/검증_결과.md, docs/sessions/Frontend.md, prompts/Frontend-01~04**. 계산 코드·자료·다른 담당 파일은 수정하지 않았다. `gpt/` 설정·빌더·지식 파일은 변경하지 않았다.
