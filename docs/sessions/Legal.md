## 문의 초안

실제 발송 전 담당 부서와 수신처를 확인하고, 필요한 범위·보유 기간·접근 통제를 구체화한다.

**자료 권리자 초안**

> 안녕하세요. 서울대학교 수강편람과 캠퍼스 이동시간을 바탕으로 비공식 학업계획 도구를 시제품으로 만들고 있습니다. 기존 TT Wizard 자료 설명에는 캠퍼스 마법 지도 이동시간 표에 별도 재사용 허락이 필요하다고 되어 있습니다. 이 자료를 별도 공개 GitHub 저장소에 복제하고 ChatGPT Edu GPT의 지식파일로 제공해 구성원과 공유하는 것이 허용되는지, 가능하다면 필요한 표시·라이선스·재배포 범위를 알려 주실 수 있을까요? 본 문의는 허락을 전제하지 않습니다.

**학교 담당 부서 초안**

> 안녕하세요. 학생이 직접 제공한 최소 이수 과목 정보로 졸업요건과 시간표를 안내하는 비공식 시제품을 검토 중입니다. 실제 학생 자료나 계정을 아직 사용하지 않았습니다. 공개된 공식 API/인증 방식이 있는지, 학생 동의가 있더라도 마이스누 화면 자동 조회가 허용되는지, 허용된다면 데이터 항목·호출 빈도·보관/삭제·보안·테스트 절차 요건을 안내해 주실 수 있을까요? ChatGPT Edu를 사용할 때 적용되는 학교 개인정보·AI 서비스 정책 담당 부서도 알려 주시면 감사하겠습니다.

## 다음 과제와 인수인계

1. 캠퍼스 마법 지도 별도 허락과 학교의 연동·개인정보 처리 답을 확인 가능한 서면으로 확보하기 전까지 현재 경계선을 유지한다. 문의는 담당자가 직접 검토·발송할 초안만 준비하며 발송하지 않았다.
2. Backend / Integrations에는 공개 공식 경로 조사와 모의 연결만 가능하다고 전달한다. API 응답이나 로그인 가능성만으로 허가·완전 조회를 뜻하지 않는다.
3. Research·Planner는 공식 공개 규정 검토, 지어낸 성적 내역으로 한 계산을 진행할 수 있다. Frontend는 개인정보 제거와 확인 필요 안내를 유지한다.
4. Document가 결과를 공통 상태 문서에 반영할 때, 여기서 확인한 사실과 미해결을 분리해 통합한다. 정책·범위 결정을 새로 내리지 않는다.
