# 로그인 뒤에는 가능한 과정을 자동으로 이어갑니다

**학교 로그인 → 이수내역·전공 정보 불러오기 → 남은 졸업요건 확인 → 시간표 3안 계산 → 선택한 과목의 강의계획서 모아보기·등록 알림**을 목표로 합니다.

- 정리일: 2026-11-06
- 상태: 자동화 목표와 연결 기준을 정리한 설계 문서입니다. 학교 로그인 연동·이수내역 자동 조회·추천·알림은 아직 구현하지 않았습니다.
- 요청 원문: [자동화 요청](../prompts/00f-로그인-이후-자동화.md)

## 학생은 최소한의 확인과 선택만 합니다

| 단계 | 학생이 하는 일 | 자동으로 처리할 일 |
| --- | --- | --- |
| 학교 연결 | 학교의 공식 로그인 화면에서 직접 로그인합니다. | 연결 가능한 방식으로 이수내역·입학연도·소속·주전공·복수전공 정보를 불러옵니다. |
| 가져온 정보 확인 | 요약을 한 번 확인하고, 빠진 필수 정보가 있으면 보완합니다. | 조회 범위와 과목을 정리하고 이수 완료·수강 중·확인 필요를 구분합니다. |
| 졸업요건 대조 | 별도 실행 없이 결과를 봅니다. | 해당 입학연도·전공에 맞는 확인된 공식 규정을 적용하고 남은 과목·학점을 찾습니다. |
| 시간표 추천 | 원하면 희망 학점·피할 시간을 알려 줍니다. | 후보 과목, 선수과목, 시간 겹침, 강의실 이동시간을 계산해 3안을 보여 줍니다. |
| 계획서 모아보기 | 시간표를 선택합니다. | 선택한 과목·분반으로 계획서 목록을 만듭니다. |
| 등록 알림 | 받을 알림을 한 번 켭니다. | 대상 과목의 계획서 등록 여부를 주기적으로 확인하고 변화를 알립니다. |

입력 경로가 로그인 연동이든 파일·붙여넣기든 같은 요건 대조·시간표 계산으로 이어집니다. 이미 확인한 정보는 다시 묻지 않고, 부족한 필수 항목만 한 번에 받습니다. 자동화 범위는 자료 읽기·계산·추천·등록 알림입니다. 실제 수강신청이나 취소를 학교 시스템에 제출하는 기능은 이번 범위에 포함하지 않습니다.

## ‘내부 브라우저 로그인’의 의미

원하는 경험은 **서비스 안에서 학교의 공식 로그인 화면을 열고, 본인이 로그인하면 수강했던 과목을 가져오는 것**입니다. 로그인 화면을 자체적으로 흉내 내거나 비밀번호를 GPT 대화에 입력하게 하지 않습니다.

내부 브라우저에서 학교 인증이 가능한지, 공식 연동 방식이 있는지, 로그인 후 어떤 자료를 읽을 수 있는지는 확인 필요입니다. 필요한 경우 공식 로그인 화면을 별도 브라우저로 여는 방법도 검토합니다. 로그인에 성공한 것과 이수내역을 읽을 수 있는 것은 별도로 검증해야 합니다. 현재 이를 지원하는 학교 API나 인증 방식을 확인했다고 주장하지 않습니다.

기존 [AGENTS.md](../AGENTS.md)의 ‘꼭 지킬 것’ 8번은 다음과 같습니다.

> 마이스누 화면을 자동으로 읽는 기능(크롬 확장 등)은 정보화본부 답이 오기 전까지 만들지 않는다.

이 조건을 해결하는 회신 자료는 현재 작업에서 확인하지 못했습니다. 이 요청은 자동화를 원하는 제품 목표로 반영하고, 실제 학교 화면을 자동으로 읽는 연결은 회신 확인 뒤 진행할 항목으로 남깁니다. GPT Actions 사용 여부도 같은 지침 9번에 따라 별도 결정 사항으로 유지합니다.

## 어떤 정보를 계산에 넘기나요?

- 학생 정보: 입학연도, 소속 학과, 주전공·복수전공 및 필요한 경우 확인된 전공 진입 연도.
- 과목 정보: 교과목번호·과목명, 공식 취득 학점, 이수 구분, 수강 학기, 확인된 이수 상태.
- 조회 정보: 자료 출처, 조회 범위·학기, 과목 수, 마지막으로 정상 확인한 시각, 누락이나 확인 실패 여부.

성적 점수·이름·전체 학번·생년월일은 추천 계산으로 넘기지 않습니다. 공식 취득 학점과 이수 상태가 확인된 과목만 완료로 계산합니다. 수강 중인 과목은 따로 보여 주며 이미 취득한 학점에 더하지 않습니다. 재수강이나 중복 인정 기준이 불명확하면 ‘확인 필요’로 둡니다.

비밀번호·인증번호·로그인 쿠키 같은 인증 정보는 GPT 입력·지식 파일·공개 저장소·로그에 넣지 않습니다. 학교 로그인 정보와 계산용 과목 표를 분리해 처리하도록 연결 방식을 정합니다. 개인 이수내역을 저장할 위치·보관 기간·삭제 방법도 연결 방식과 함께 확정하며, 공개 자료와 섞지 않습니다. 시연과 테스트에는 지어낸 학생 자료만 사용합니다.

## 자동 진행 중 문제가 생기면

| 상황 | 보여 줄 내용과 처리 |
| --- | --- |
| 로그인은 됐지만 자료를 읽지 못함 | ‘로그인 완료 · 이수내역 불러오기 실패’를 구분합니다. 이수내역이 없다고 처리하지 않습니다. |
| 일부 학기·일부 페이지만 읽힘 | ‘일부 자료만 확인됨’과 범위를 표시합니다. 전체 졸업요건 충족 여부를 확정하지 않습니다. |
| 정상 조회 결과가 비어 있음 | 전체 조회 범위와 공식 빈 결과가 확인된 경우에만 ‘이수 기록 없음’으로 표시합니다. |
| 입학연도·전공 정보가 제공되지 않음 | 빠진 필수 항목만 한 번에 묻습니다. 수강 과목으로 전공을 추측하지 않습니다. |
| 로그인 만료·학교 접속 오류 | 해당 자료의 갱신을 멈추고 다시 연결할 필요를 표시합니다. 이전 정상 자료는 확인 시각과 함께 보여 주고 최신으로 가장하지 않습니다. |
| 다른 계정으로 변경·연결 해제 | 이전 계정의 이수내역·추천·개인 알림 설정을 분리하고 해당 연결의 확인 작업을 멈춥니다. 서로 다른 계정의 자료를 합치지 않습니다. |
| 과목·강의실·졸업요건 자료가 바뀜 | 달라진 자료와 영향을 보여 주고 관련 계산을 다시 합니다. 학생이 선택한 시간표 자체를 말없이 교체하지 않습니다. |
| 적용할 공식 요건이 없거나 해석이 불명확함 | 해당 항목을 ‘확인 필요’로 두고, 확인된 범위로만 결과를 설명합니다. |
| 강의계획서 조회만 실패함 | 이수내역·시간표 결과는 유지하고 계획서 상태에 오류를 표시합니다. |

자료를 다시 불러오면 변경된 과목·학점·전공을 요약해 보여 줍니다. 새 자료를 검증하기 전에 이전 정상 자료를 지우지 않습니다. 반복 실행으로 같은 과목이 중복되거나 이미 보낸 계획서 알림이 다시 나가지 않도록 합니다.

규정이 바뀌었다고 새 문서를 모든 학생에게 바로 적용하지 않습니다. 공식 문서의 적용 학번·전공 진입 연도와 해석을 확인한 버전만 계산에 씁니다. 알림의 자세한 판정 기준은 [강의계획서 설계](강의계획서_모아보기와_알림.md)를 따릅니다.

## 구현을 연결하는 순서

1. **공통 계산부터:** 파일·표로 받은 지어낸 이수내역을 정리하고 요건 대조·시간표 계산에 연결합니다. 이는 기존 작업 2~4의 내용입니다.
2. **한 번에 진행되는 흐름:** 정보 확인 이후 계산과 계획서 목록 구성이 이어지게 하고, 가상의 연결 응답으로 성공·부분 조회·만료 상황을 검증합니다. 모의 연결은 실제 학교 로그인으로 소개하지 않습니다.
3. **학교 연결:** 정보화본부 회신과 지원되는 인증·조회 방식을 확인한 뒤 같은 입력 형식으로 연결합니다. 내부 브라우저 방식이 가능한지도 이 단계에서 검증합니다.
4. **정기 확인과 알림:** 공식 조회 경로·확인 주기·실행 환경·알림 수단을 연결합니다. 앱을 열지 않은 동안에도 확인할 수 있는지는 선택한 실행 방식으로 검증합니다.

학생의 개인 로그인 유지와 공개 강좌·계획서 조회는 같은 작업이라고 가정하지 않습니다. 공식 경로가 따로 제공된다면 분리해 연결합니다. 정기 확인을 위해 비밀번호를 보관하는 방식은 채택하지 않습니다.

## 확인할 사항과 검증 기준

| 확인할 곳 | 확인할 내용 |
| --- | --- |
| 정보화본부·학사 시스템 담당 부서 | 기존 문의 회신, 허용·지원되는 조회 방식, 읽을 수 있는 항목, 내부 브라우저 인증 가능 여부, 연결 만료·해제 처리. |
| 프로젝트 구현 단계 | 개인 자료 저장 위치·삭제 방법, 정기 확인을 실행할 환경, 실제 사용할 알림 수단. |
| 지어낸 자료를 사용하는 테스트 | 전체·부분·빈 조회 구분, 수강 중 과목 제외, 중복·재수강 처리, 계정 변경 시 자료 분리, 재실행·재시도 시 중복 알림 방지. |
| 공모전 시연 | 학생이 실제 입력한 횟수, 자동으로 처리된 단계, 처리 시간, 실패 시 안내. 실제 연동과 모의 시연을 구분하고 측정한 결과만 성과로 기록. |

현재는 위 흐름을 문서로 정리한 단계입니다. 학교 자동 연동이나 알림이 작동한다고 표시할 수 없으며, 자료 준비용 기존 테스트의 통과가 로그인 연결 검증을 뜻하지 않습니다.
