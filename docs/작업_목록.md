- tests: 지어낸 학생 3명(동물생명공학전공 2학년, 생명과학부 복수전공, 화학생물공학부 복수전공 3학년)

- planner/courses.py: 남은 전공필수 → 권장 학년·학기 → 선수 과목 충족 → 개설 가능성 순으로 후보를 고른다. 목표 학점 기본값은 15~18이고 학생이 말하면 따른다. 피하고 싶은 요일·시간과 주로 오는 곳도 받는다.
