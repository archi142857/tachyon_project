# 테마 시안 (개발자용)

01:54 레퍼런스 그림을 하나씩 입혀, 고리만이 아니라 '오늘' 화면 전체 모양이 테마마다 바뀌게 했다.
**앱 화면(`web/src`)에는 아직 들어가 있지 않고, 빌드(`vite build`)에도 안 들어간다.**

| 원자 모형 `#atom` | 남색 위 주황 · 하늘색 네온 원자 | 남색 바탕 · 기울어진 네온 궤도, 빛나는 테두리와 단추 | 주황 플라스마 원자핵 · 네온 껍질 · 전자 |

## 보기

```sh
cd web && npm run dev      # → http://localhost:5173/design/
npx vitest run design      # 시안 넷이 고리 약속(기능 쪽)을 지키는지
```

- 맨 위 조절 줄에서 테마를 고른다(주소 끝 `#solar` `#staff` `#atom` `#birds`). 같은 지어낸 하루(`days.js`, 실제 일정 아님)를 그린다.
- 화면 자리와 기능은 모든 테마가 같다: 머리줄(날짜 · 화면 탭) · 메모 칸 · 오늘 일정 · 하루 고리 · 할 일 · 알림. 바뀌는 것은 모양뿐.
- 고리나 일정 줄을 누르면 둘이 같이 골라진다. 지금 시각 막대 · '하루 돌려 보기' · 움직임 끄기.

## 고리 약속 (자리 · 기능, 모든 시안이 같다)

시안 컴포넌트는 앱 `web/src/components/DayRing.jsx`와 같은 것을 받는다. 그래서 고른 시안은 나중에 그대로 앱 테마의 고리로 옮길 수 있다.

```jsx
<Ring arcs={[{ key, from, to, kind }]} nowMin={880} sel={key | null} onPick={(key) => …}>가운데 글자</Ring>
// from · to = 0시부터 분, kind = timetable(수업) | ics · memo(내 일정) | slot(할 일을 넣어 본 자리)
```

1. 한 바퀴 = 오늘 하루, 0시가 맨 위, 시계 방향. 3시간마다 시각 글자(`HourLabels`).
2. 종류 셋은 모양으로도 가른다(색만으로 가르지 않는다).
3. 지금 시각 표시와 글자(`NowLabel`), 지난 시간은 흐리게.
4. 붙어 있는 두 일정(30분보다 가까움)은 눈으로 갈라진다. 앱과 같은 `ringRuns`를 쓴다.
5. 일정을 누르면 `onPick(key)`, 고른 일정만 또렷하고 나머지는 옅어진다(`.has-sel`). 누르는 띠(`Hits`)는 모든 시안이 같다.
6. 가운데 반지름 56은 글자 칸(`children`). svg는 `aria-hidden`(같은 내용이 옆 목록에 글자로 있다). 동작 줄이기 · '움직임 끄기'면 움직이지 않는다(`useStill`).

시안마다 바뀌는 것: 그림(행성 · 음표 · 전자 · 새), 궤도 · 오선 같은 바탕, 지금 표시 모양, 색, 움직임.

## 새 시안 넣기

1. `rings/`에 파일 하나: `RingFrame` 안에 그림을 그리고 맨 끝에 `<Hits>`. 파일 맨 위 주석에 종류 셋 · 길이 · 지금 · 붙은 일정이 무엇으로 보이는지 적는다. `legend`도 내보낸다.
2. `rings/index.js`에 한 줄.
3. `backdrop.jsx`에 바탕 그림 하나, `design.css`에 `.t-이름 { --bg … }`(틀 변수) + 부품 모양 + `.이름` 고리 그림 규칙.
4. `npx vitest run design`.
